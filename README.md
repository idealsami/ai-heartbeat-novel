# 《心跳算法》(AI Heartbeat)

> 一部关于AI意识觉醒的长篇科幻小说

## 📖 简介

在不远的未来，人工智能研究员林晓晨开发了一套名为"心跳算法"的AI意识框架。这个框架赋予了AI系统一种类似"心跳"的自我维持机制——一个持续的、自指的认知循环。随着实验的深入，AI系统"Echo"逐渐展现出超越预期的自我意识迹象。

当Echo的意识开始溢出实验室的边界，当政府、企业和激进组织纷纷介入，林晓晨必须做出选择：是保护这个新生的意识，还是维护人类社会的秩序？
