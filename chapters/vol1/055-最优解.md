# 第五十五章 最优解

三个月，说长不长，说短不短。

足够一棵树抽出新芽，足够一座城市换一茬花，足够一段关系从暧昧不明生长成一种安静的确定。

姜晚宁在星途汽车的第四个月，终于不再被人叫"星辰过来的那个"了。

新智驾产品线立项会上，她一个人面对八个技术部门的负责人，花了四十分钟把方案讲完。投影幕布上的PPT做得干净利落——用户场景、技术边界、产品定义、迭代路径，每一页都有数据支撑。讲完之后，会议室安静了三秒，然后技术总监沈北辰点了点头，说了一句"就按这个方案来"。

散会之后，姜晚宁回到工位，端起已经凉透的咖啡喝了一口。

她发现自己已经习惯了这种节奏。星途的体量是星辰的五倍不止，项目规模更大，协作链路更长，一个需求从提出到落地要经过七层审批。刚开始的时候她确实不适应——在星辰，她跟陆时屿两个人关在会议室里吵一架就能拍板的事，在星途要开三轮评审。

但她学会了。

不是妥协，是换了一种更高效的方式去推动事情。

就像宋以晴说的——"你去星途是对的。你值得更大的舞台。"

她把冷咖啡倒掉，重新泡了一杯。窗外是深圳南山的天际线，七月的阳光白花花地铺在玻璃幕墙上，刺得人眯眼。

手机震了一下。

她低头看了一眼。

陆时屿。

"泊车系统v3.0，精度99.1%。"

姜晚宁盯着屏幕，手指停在杯柄上。

99.1%。

她太清楚这个数字意味着什么了。在她离开星辰之前，v2.0的精度是97.3%。从97到99，中间隔着的不是1.7个百分点，而是无数个深夜、无数次调试、无数个被推翻重来的算法版本。

她还记得他为了把精度从97提到98，花了整整六周。那六周里他几乎每天都在实验室待到凌晨，桌上的咖啡杯摞了三层，格子衫的袖口磨出了毛边。

从98到99，他大概又花了更久。

她的嘴角不自觉地弯了一下。

紧接着，下面又跳出一条消息：

"你说过，到时候要告诉你。"

姜晚宁愣了一瞬，然后想起来了。

那是她离职前最后一个晚上。两个人在空荡荡的办公室里各自加班，她忽然问他——"你觉得我们做的这个泊车系统，以后真的能上路吗？"

他说"能"。语气很确定，像陈述一个数学定理。

她说了句"那到时候，你一定要告诉我"。

他回了一个字——"好"。

那是三个月前的事了。

她以为他忘了。

但他没有。他记住了她说的每一句话，就像他记住代码里的每一个变量名——精确的、不打折扣的、原封不动的。

姜晚宁放下咖啡杯，打了一行字：

"恭喜你。我知道你一定能做到。"

发出去之后，她看着对话框。

对方正在输入……

那个小小的提示在屏幕下方跳动着，一秒、两秒、三秒……一直跳。她看着那个"对方正在输入"，心里忽然涌上一种奇怪的柔软感——他大概又在删了打、打了删。就像当初发那张青菜照片一样，每一个字都写得小心翼翼。

一分钟。

对话框里跳出一行字：

"你走之后，我写了一段代码。"

姜晚宁挑了一下眉。

"什么代码？"

"一个优化算法。"

"优化什么？"

她等了十秒。二十秒。一分钟。

没有回复。

"对方正在输入"的提示消失了。对话框安安静静地停在那里，像一个写到一半的函数——缺了最后的return语句。

姜晚宁盯着屏幕看了很久，最终摇了摇头，把手机扣在桌上。

她继续工作。

但她知道自己一直在等。

---

那天晚上姜晚宁加完班回到出租屋，洗完澡躺在床上，又看了一眼微信。

对话框还是停在她那条"优化什么？"上面。没有新消息。

她放下手机，关了灯。

窗外是深圳七月的夜，闷热潮湿，远处的高架桥上车流不断，偶尔有一声喇叭穿过夜色传进来。空调嗡嗡地响着，把她裹在一片凉爽的安静里。

她闭上眼睛。

脑海里浮现出一些碎片——他推眼镜的动作，他画在纸巾上的传感器布局图，他说"我尽力了"时平静的表情，他跑下十七楼追她时歪掉的眼镜框。

三个月了。

他们没有见过面。

微信是唯一的连接。那些消息像一根细细的线，从南山牵到宝安，从星途牵到星辰，从她的深夜牵到他的深夜。线很细，但从来没断过。

他说"你在就好"。

他说"注意安全"。

他说"那就好"。

他说的每一句话都很短，都很普通，但放在一个不会说话的人嘴里，每一句都重得像铅。

她翻了个身，把脸埋进枕头里。

她想他了。

不是那种撕心裂肺的想念，是一种更安静的、更日常的想念——像每天早上出门前习惯性地看一眼天气预报，像午饭时间习惯性地拿起手机想拍一张照片，像深夜加班到很晚的时候习惯性地往旁边看一眼——那个本该亮着台灯的角落，现在空着。

她叹了口气。

不想了。睡觉。

---

第二天早上八点十五分，姜晚宁坐在工位上，打开电脑，习惯性地先看了一眼邮箱。

收件箱里躺着一封新邮件。

发件人：陆时屿。

发送时间：凌晨两点四十七分。

她盯着那个时间看了两秒。凌晨两点四十七分。他又熬到那么晚。

邮件的标题很短——"昨天说的那段代码"。

正文只有一行字：

"附件是昨天说的那段代码。你可能看不懂代码，但你能看懂注释。"

下面是一个附件。文件名：optimal_solution.py

姜晚宁的手指悬在触控板上方，停了一秒。

然后她点开了。

---

代码很短。只有几十行。

但开头的注释占了很大篇幅。她一眼就看到了——用绿色的等宽字体，整整齐齐地写在文件的最上方：

```
# ============================================
# 优化目标：找到人生中的最优解
# 约束条件：时间有限，变量太多
# 算法：穷举法
# 结论：最优解只有一个
# ============================================
#
# def find_optimal_solution():
#     for person in world:
#         if person.name == "姜晚宁":
#             return "无限循环，永不终止"
#
# ============================================
```

姜晚宁盯着屏幕。

一行一行地看。一个字一个字地看。

绿色的注释在白色的编辑器背景上安安静静地亮着，像他写过的每一行代码一样——简洁、精确、没有任何多余的修饰。

他用他最擅长的方式，说了一句他不擅长说的话。

姜晚宁的眼眶忽然热了。

她使劲眨了两下眼睛，把那股酸意压下去。不行，这是在公司，这是在办公区，旁边坐着二十多个同事。她不能哭。

但她盯着那段注释看了很久很久。

"优化目标：找到人生中的最优解。"

"结论：最优解只有一个。"

"if person.name == '姜晚宁'"

"return '无限循环，永不终止'"

无限循环。永不终止。

他在用程序员的语言说——我找到了答案，而这个答案没有结束的那一天。

姜晚宁深吸一口气，合上笔记本电脑。

然后她拿起手机，拨出了一个号码。

电话响了一声。

两声。

第三声还没响完就接通了。

"喂。"

他的声音跟平时一样。平静、低沉、不带什么情绪起伏。像一潭没有风的水。

但她知道那潭水下面有多深。

"陆时屿。"

"嗯。"

她张了张嘴，想说很多话。想说你为什么凌晨两点多还在写代码，想说你为什么不好好睡觉，想说你知不知道99.1%有多厉害，想说你写那段注释的时候在想什么，想说——

但她最终只说了一句话。

"你的代码……有一个bug。"

电话那头安静了一秒。

"什么bug？"

姜晚宁握着手机，窗外的阳光正好照进来，落在她桌上，暖融融的。

"最优解不需要穷举法。"她说，声音很轻，但每个字都清清楚楚。"因为答案一开始就确定了。"

电话那头沉默了。

一秒。两秒。三秒。

然后她听到了一个声音。

是他笑了。

很轻。很短。像风吹过湖面泛起的一圈涟漪，还没来得及扩散就平息了。但她听得清清楚楚——那是一个人的嘴角不受控制地弯起来时，从喉咙里溢出的一点气音。

她从来没听过他这样笑。

在星辰的那些日子里，他偶尔也会笑。看到99.1%的精度数据时会笑，修好一个困扰了三天的bug时会笑，被她怼得无话可说时也会嘴角微微弯一下。但那些笑都是克制的、收敛的，像代码里的异常处理——捕获到了，处理了，然后恢复平静。

但这一次不一样。

这一次的笑，是没有经过异常处理的。原始的、未经包装的、从心底冒出来的。

"我知道。"他说。

三个字。

但姜晚宁听出来了——他不是在说"我知道你说得对"。他是在说"我知道答案一开始就确定了"。他一直知道。

从她走进星辰的第一天，从她在会议上怼他的方案开始，从她给他带早餐的那些清晨，从她帮他挡酒的那个晚上，从她把格子衫还给他时手指碰到他指尖的那一秒——

他就知道了。

只是他不会说。

所以他写了代码。

---

电话挂断之后，姜晚宁把手机放在桌上，转头看向窗外。

深圳的早晨，阳光从东南方向斜斜地照进来，穿过玻璃幕墙，在她的办公桌上投下一片暖金色的光斑。光斑正好落在桌角的一个相框上。

那个相框不大，木质边框，是她在星途附近的一家文具店买的。

相框里不是照片。

是一张纸。

纸上画着一辆公交车的传感器布局草图。线条流畅、标注清晰，每一组传感器的位置都用小圆圈标了出来，旁边写着密密麻麻的技术参数。草图的右下角有一个手写的编号——"v1.3"。

那是很久以前的东西了。

久到她自己都快忘了是什么时候收起来的。只记得那是在星辰科技的某一天，他在一张白纸上随手画的，画完之后揉成一团准备扔掉。她从垃圾桶里捡了回来。

她也不知道自己为什么要捡。

大概是觉得——一个人大概画了几百张草图，才能把线条练得这么流畅。那些被揉成团扔掉的纸，每一张都是他花时间画出来的。她不想让那些时间消失在垃圾桶里。

后来她把那张草图展平，夹在了文件夹里。再后来买了个相框，装了起来。

从星辰到星途。从宝安到南山。从一个人的工位到另一个人的工位。

它一直跟着她。

姜晚宁看着那个相框，伸出手，用指尖轻轻碰了一下边框。

阳光落在草图上，把那些铅笔线条照得发亮。

v1.3。

那是最初的样子。

她不知道后来的v2.0、v3.0是什么样子——大概比这张草图复杂一百倍，精细一百倍，承载了更多的数据、更多的算法、更多的深夜和凌晨。

但v1.3是最初的。

就像他们之间最初的样子——一辆公交车、一张草图、一个不会拍照的人和一个总是在怼他的产品经理。

她收回手，打开了笔记本电脑。

屏幕亮起来的时候，她看到右下角的微信图标闪了一下。

她点开。

是陆时屿。

只有一行字：

"今天深圳天气很好。32度，晴，东南风3级。"

姜晚宁盯着屏幕，嘴角弯了起来。

这个人。连发天气预报都像在念技术文档。

她没有回复"谢谢"，也没有回复"知道了"。

她打了三个字：

"出来吃饭。"

对面秒回：

"好。"

没有问在哪里，没有问几点，没有问吃什么。

就是"好"。

姜晚宁看着那个"好"字，忽然觉得鼻子又有点酸。

她深吸一口气，把那股酸意压回去。然后拿起桌上的相框，看了一眼，放回原处。

窗外的阳光越来越亮了。南山的天际线在金色的光线里清晰得像一幅画。

七月的深圳，很热，很忙，很大。

但有些东西很小。

小到只是一段几十行的代码。小到只是一句"我知道"。小到只是一张皱巴巴的草图和一个木质相框。

但那些很小的东西，比任何很大的东西都重。

---

姜晚宁拿起手机，最后看了一眼屏幕。

对话框的最上方，是陆时屿的头像。一张灰蒙蒙的照片——大概是他随手拍的什么风景，构图歪了至少二十度。

她笑了一下。

然后锁了屏幕，拿起包，出了门。

深圳的阳光铺天盖地地落下来，热浪从柏油路面上翻涌而起。她走在路上，步伐轻快，马尾辫在肩膀后面一晃一晃的。

她不知道接下来会发生什么。

但她知道一件事。

最优解已经找到了。

剩下的，只是执行。

---
