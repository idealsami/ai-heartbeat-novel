# 第120章 代码情书（续）

周一早晨，姜晚宁到公司的时候，陆时屿已经坐在工位上了。

她远远地看了他一眼，他正对着屏幕敲代码，黑框眼镜映着屏幕的蓝光，格子衫袖口挽到手肘，整个人专注得像一尊雕塑。

自从上周吵完架又和好，两个人之间的气氛反而比之前更好了。那种好，不是刻意的甜蜜，而是一种微妙的默契——好像彼此都更确定了一点什么。

姜晚宁收回目光，打开电脑，开始处理积压的需求文档。

上午十点半，她收到了陆时屿的微信消息。

「今天下午三点，来我工位一趟。」

姜晚宁挑了挑眉，打字：「什么事？」

「有个Demo需要产品经理验收。」

姜晚宁看了眼自己的排期，回复：「下午三点有会，四点可以。」

「那就四点。」

她放下手机，没多想。陆时屿平时做Demo给她看也不算罕见，毕竟智能驾驶项目的交互逻辑都需要产品确认，他们之间这种工作上的往来一直很顺畅。

但她没注意到，陆时屿发完消息之后，嘴角微微上扬了一下。

——

下午四点零三分，姜晚宁抱着笔记本电脑走到算法组的工位区。

陆时屿的位置在靠窗的角落，旁边放着一盆她之前送的绿萝，叶子长得很好，垂下来快要碰到桌面上的显示器底座。

"来了。"陆时屿抬头看她，表情很平静，跟她平时见他汇报技术方案时一模一样。

"嗯，Demo呢？"姜晚宁在他旁边的椅子上坐下，翻开笔记本电脑，准备记录。

"等一下。"陆时屿转过身，修长的手指在键盘上敲了几下，"写了一个小工具，想让你看看交互效果。"

"什么工具？"

"一个……数据可视化的小Demo。"他说这话的时候，语气跟平时没有任何区别，公事公办得像在念技术文档，"之前做路径规划的时候顺手写的，觉得交互方式可能对产品有参考价值。"

姜晚宁点点头："行，你演示一下。"

陆时屿点了下鼠标。

屏幕上弹出一个黑色的窗口，看起来像是某种命令行界面。窗口的标题栏写着——

`Optimal_Solution_Demo v1.0`

姜晚宁下意识地念出来："最优解Demo？"

"嗯。"陆时屿推了一下眼镜，"你看屏幕就行。"

窗口里开始逐行打印内容，速度不快，像是有人在一行一行地敲——

```
> Initializing system...
> Loading dataset: my_life.dat
> Processing...
```

姜晚宁一开始真的以为这是个技术演示。她甚至微微前倾，认真地盯着屏幕看。

然后，下一行出现了。

```
> ERROR: dataset incomplete.
> Reason: Missing core module.
```

她愣了一下，转头看陆时屿。

他没有看她，目光平静地盯着屏幕，手指交叉放在键盘边缘。

屏幕上的文字继续滚动——

```
> Searching for missing module...
> Query: "What makes a life complete?"
> Processing...
```

停顿了两秒。

```
> Result found.
> Module name: 姜晚宁
> Match rate: 100.00%
```

姜晚宁的手停在笔记本电脑的触控板上，整个人僵住了。

屏幕上的文字还在继续，像是根本不知道坐在面前的人已经看傻了——

```
> Loading module: 姜晚宁...
> █████████████████████████ 100%
> Module loaded successfully.
> Recompiling life...
> All errors resolved.
```

然后，命令行窗口的界面突然变了。

黑色的背景上，出现了一行注释——

```python
# 致姜晚宁：
# 你是我调试了二十八年才找到的那个bug
# 不，不是bug
# 你是那个——让整个系统终于能跑起来的关键函数
```

姜晚宁的呼吸停了一拍。

新的代码开始逐行出现，每一行都带着注释，像是一个人在慢慢地、笨拙地、却认真无比地说话——

```python
def find_meaning_of_life():
    """
    这个函数的返回值，我找了很久。
    试过很多算法，贪心、动态规划、回溯……
    都不对。
    直到遇见你。
    """

    # 我不太会说漂亮话
    # 每次想夸你，脑子里冒出来的都是"你这个需求提得不错"
    # 但其实我想说的是——
    # 你笑起来的样子，比所有通过测试的代码都好看

    you = Person(name="姜晚宁")

    # 你第一次对我笑的时候
    # 我的心率从72飙升到112
    # 不是bug，是feature

    # 你跟我吵架的那天晚上
    # 我写了三百行代码，全部删掉
    # 因为脑子里全是你说"你根本不懂我"那句话
    # 后来我想了很久
    # 你说得对，我确实不懂
    # 但我可以学

    # 我学不会说"我想你"
    # 但我会在你加班的时候点你爱喝的奶茶
    # 我学不会制造浪漫
    # 但我会记住你每一个需求文档的deadline
    # 我学不会甜言蜜语
    # 但我可以保证——
    # 我写的每一行代码，debug的每一个夜晚
    # 都是为了成为更好的人
    # 为了配得上你

    return you  # 最优解
```

屏幕上的光标闪烁了一下，然后，整个窗口安静了两秒。

下一秒，黑色的屏幕上，缓缓绽开了一朵花。

那朵花是用代码一行一行画出来的。花瓣从中心旋转展开，颜色从浅粉渐变到深红，每一片花瓣都带着微微的弧度，像是被风吹动了一下。

姜晚宁看得出来，那不是什么现成的动画素材。那是用算法一笔一笔计算出来的曲线——贝塞尔曲线、极坐标方程、逐帧渲染。

他大概是花了很长时间写的。

花完全展开之后，花瓣轻轻颤动了一下，像是在呼吸。

然后，花的下方，缓缓浮现出一行字——

**"这个世界的最优解，是你。"**

字体不大，白色的，安安静静地待在屏幕下方。

没有音效，没有特效，没有任何花哨的东西。

只有一行字，一朵用代码画出来的花，和一个坐在旁边、安安静静看着她的人。

姜晚宁盯着屏幕看了很久。

久到旁边路过的同事好奇地往这边瞥了一眼，又识趣地走开了。

她的眼眶一点一点地红了。

不是那种突然被感动到的红，是慢慢涨上来的——像潮水，像日出，像一个迟来的、但终于抵达的回应。

"你……"她开口，声音有点哑，"你什么时候写的？"

"上周。"陆时屿的声音很平静，但他放在键盘旁边的手微微攥了一下，"就是……吵完架那天晚上。"

姜晚宁低下头，用手背快速擦了一下眼角。

"你不是说你不会写情书吗。"她的声音闷闷的。

"我确实不会。"陆时屿顿了一下，"所以我用了我会的方式。"

姜晚宁没有说话。

屏幕上的花还在轻轻颤动，那行白色的字安静地亮着。

"你要是觉得……"陆时屿推了一下眼镜，语气有一丝不确定，"太幼稚了的话——"

"闭嘴。"姜晚宁小声说。

陆时屿闭嘴了。

姜晚宁深吸一口气，把眼泪逼回去，然后站起身，抱着笔记本电脑，快步走回了自己的工位。

陆时屿看着她的背影，喉结微微滚动了一下。

他低下头，盯着屏幕上那朵自己花了三个晚上调试参数才画出来的花，心跳得很快。

——

姜晚宁回到工位上，把笔记本电脑放下，盯着自己的屏幕看了整整五分钟。

屏幕上什么都没有，是她刚才打开的需求文档。文档上的字她一个都看不进去。

她的心跳声大得吓人。

旁边工位的林知意探过头来："晚宁姐，你眼睛怎么红了？"

"过敏。"姜晚宁面不改色地说。

"哦……"林知意半信半疑地缩回去了。

姜晚宁深呼吸了好几次，才稳住情绪。她拿起手机，打开微信，找到陆时屿的对话框。

她打了好几个版本的消息，又全部删掉。

最后，她只打了六个字——

**「你写的代码，我看懂了。」**

发送。

对面几乎是秒回。

**「那你愿意做我的最优解吗？」**

姜晚宁盯着这条消息看了十秒钟。

她的嘴角不受控制地翘了一下，又抿回去，又翘起来。

她故意不回。

一分钟过去了。

她能想象陆时屿此刻的样子——坐在工位上，手机屏幕朝上放在桌上，每两秒看一次，表面平静，内心大概已经把所有最坏的结果都过了一遍。

因为他就是这样的人。不会追着问，不会连发消息轰炸，只会安静地等，然后在心里把焦虑一层一层地垒起来。

又过了三十秒。

姜晚宁终于打字——

**「我考虑一下。」**

发完之后，她把手机扣在桌上，嘴角的弧度已经压不住了。

一分钟后，她拿起手机，看到陆时屿回了一个「好」。

只有一个字。

但她知道，这个字背后，是一个理工直男鼓起了全部的勇气。

姜晚宁深吸一口气，打了两个字，发过去——

**「好。」**

就一个字，跟他的"好"一样简短。

但她知道他看得懂。

——

三分钟后，她的手机震了一下。

陆时屿发来一条消息：

**「那我们现在算……正式在一起？」**

姜晚宁差点笑出声来。

他们明明已经在一起快两个月了。

但她懂他的意思。之前在一起是顺其自然，而今天，是他认认真真地、用自己的方式，重新问了一次。

**「算。」**她回。

然后她又加了一句：**「你的代码写得不错，下次记得加个用户手册。」**

过了十几秒，陆时屿回：**「好，下次迭代。」**

姜晚宁对着手机屏幕笑了很久。

——

那天晚上，姜晚宁加班到八点半。

收拾东西准备走的时候，她发现工位上多了一杯奶茶。杯壁上贴着一张便利贴，上面是陆时屿的字迹——工工整整的，像印刷体一样——

**"三分糖，少冰。你的需求文档里写的。"**

姜晚宁把便利贴撕下来，折好，放进了手机壳的背面。

然后她拿起奶茶，喝了一口。

三分糖，少冰。

温度刚刚好。

——

走出公司大楼的时候，夜风凉凉的。

姜晚宁站在路灯下，低头看了看手机壳背面那张便利贴，又抬头看了看天。

城市的夜空看不到星星，但路灯把她的影子拉得很长。

她突然想起屏幕上的那行代码——

```python
return you  # 最优解
```

这个世界上有很多种写代码的方式。

有人用算法解决问题，有人用代码搭建世界。

而陆时屿用代码，写了一封她这辈子收到过的最好的情书。

姜晚宁低头笑了一下，把奶茶举起来，对着夜空轻轻碰了一下。

"最优解。"她小声念了一下这两个字，然后转身往地铁站走去。

手机在口袋里又震了一下。

是陆时屿发的最后一条消息——

**「晚安，最优解。」**

姜晚宁在地铁站入口停下来，打了四个字发过去——

**「晚安，笨蛋。」**

然后她收起手机，走进了地铁站。

身后，城市的夜风轻轻吹过，把她马尾的发梢扬起来。

她忽然觉得，今天的风，好像也带着一点甜味。

——

那天深夜，陆时屿坐在出租屋的书桌前，打开了那Demo的源代码文件。

他翻到最下面，看着那行注释——

```python
return you  # 最优解
```

然后，他在下面又加了一行——

```python
# 版本记录：
# v1.0 — 第一次跑通，她看哭了。
# v1.1（计划中）— 加入"结婚"功能模块。
```

写完之后，他自己也愣了一下，然后推了推眼镜，关掉了电脑。

屏幕暗下来，房间里只剩下窗外透进来的城市微光。

他靠在椅背上，嘴角浮起一个很淡很淡的弧度。

心跳算法，第一次迭代成功。

最优解已确认。

系统运行正常。

（第120章 完）
