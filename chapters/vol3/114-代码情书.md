# 第114章 代码情书

周五晚上，姜晚宁加完班回到公寓，把自己摔进沙发里。

手机屏幕亮了一下。

是陆时屿发来的一条消息，简短得一如既往：

**"发你一个文件，记得打开。"**

紧接着，一个.zip压缩包出现在聊天窗口里。

姜晚宁盯着那个文件名看了几秒——`optimize_your_world.zip`。

"优化你的世界？"她嘟囔了一句，"这人又在搞什么名堂。"

她把文件下载到电脑上，解压后发现里面只有一个Python文件，文件名叫`demo.py`。

姜晚宁双击打开，代码编辑器里跳出一段代码。她皱了皱眉，一行一行往下看：

```python

# Project: MyOptimalSolution
# Author: Lu Shiyu (陆时屿)
# Date: 2026-05-04
# Description: A demo for the most important person in my life
# ============================================================

# 不是作业，不是面试题，不是论文。

# ----------------------------------------

first_sight = "2025年秋天，电梯里"

# 以为是楼层太高，电梯失重

emotion = None  # 情绪，初始为空

# 不是因为咖啡
```

姜晚宁的指尖微微一顿。

她把椅子拉近了一些，继续往下看。

```python
# ----------------------------------------
# 核心函数定义
# ----------------------------------------
def calculate_heartbeat(jiang_wanning):
    """
    每次见到姜晚宁，心率变化函数。
    
    参数:
        jiang_wanning: 唯一输入，不可替代
    
    返回值:
        float: 心跳频率（次/分），异常偏高
    
    注意事项:
        - 此函数不可复现于其他输入
        - 已测试过无数遍，结论唯一
    """
    # 见到你的时候
    # 心率从72升到120
    # 这不是bug，是feature
    normal_rate = 72
    seeing_you_rate = 120
    
    # 你笑的时候
    # 心率会再涨30
    if jiang_wanning.is_smiling:
        seeing_you_rate += 30
    
    # 你看我的时候
    # 会短暂停跳，然后补偿性加速
    if jiang_wanning.is_looking_at_me:
        seeing_you_rate += 20  # 保守估计
    
    return seeing_you_rate
```

姜晚宁抿了抿唇，感觉自己心跳也不太对劲了。

她继续滚动鼠标。

```python
# ----------------------------------------

# ----------------------------------------

    ("秋天", "电梯相遇", "心跳异常，归因为失重"),

# 以上所有"归因"，都是借口。
# 工程师的通病——
# 遇到无法解释的异常，总想找个合理的reason。
# 但喜欢你这件事，
# 就是那个无法被优化掉的全局变量。
```

姜晚宁的眼眶开始发酸。

她使劲眨了眨眼睛，手指继续滑动滚轮。


代码到这里就结束了。

但姜晚宁注意到，文件最底部还有一行注释：

```python
# PS: 运行这个文件，有彩蛋。
# PPS: 我写了三个晚上。
# PPPS: 花是我用贝塞尔曲线手算的控制点，不是抄的。
```

姜晚宁盯着那个"PS"看了几秒，退出编辑器，打开了终端。

她深吸一口气，在命令行输入：

```
python demo.py
```

回车。

屏幕上先是一行一行地打印出文字——

```
正在搜索最优解...
搜索空间: 全世界
已迭代: 28年 x 365天 x 24小时 x 60分钟
正在排除干扰项...
排除完毕。
置信度: 100%
```

然后，终端窗口闪了一下，弹出了一个新的图形窗口。

一朵花，正在屏幕上缓缓绽开。

是用算法动态生成的——每一片花瓣都沿着贝塞尔曲线展开，从花蕊处一点一点向外绽放，像延时摄影里的真实花朵。颜色是渐变的，从花蕊处的鹅黄，过渡到花瓣边缘的浅粉，再到最外层的淡白。

姜晚宁认得出来，这是一朵玫瑰。

不是那种网上随便下载的素材——每一条曲线都带着手工计算的痕迹，花瓣的弧度不完全对称，有几处控制点的位置稍有偏移，恰恰因为这些不完美，让它看起来更像一朵真正的花。

姜晚宁伸手捂住了嘴。

花完全绽放之后，屏幕上浮现出一行字，用的是程序员常用的等宽字体，但每个字都像是敲在她心上：

**「这个世界的最优解，是你。」**

然后，花下面出现了一行小字，像是代码里的最后一行注释：

`// 陆时屿写了三个晚上，删掉了一百二十七个版本。`

姜晚宁坐在电脑前，一动不动。

屏幕上的花还在微微摇曳，像有风吹过。那些贝塞尔曲线构成的花瓣轻轻地、有节奏地起伏着，像呼吸。

她的眼眶终于红了。

不是因为委屈，不是因为难过。

是因为——

那个连"晚安"都要靠系统提醒才会说的人，那个约会时会把行程做成Excel表格的人，那个说"喜欢"时会先清嗓子、然后面无表情地说出最滚烫的话的人——

他居然，用了三个晚上，写了一百二十七个版本，用贝塞尔曲线手算控制点，做出了一朵会呼吸的花。

就为了告诉她：她是他的最优解。

姜晚宁吸了吸鼻子，打开手机。

她对着聊天框打了几个字，删掉，又打，又删掉。

最后发出去的只有一句：

**"你写的代码，我看懂了。"**

发送。

她把手机扣在桌上，心跳快得不像话。

十秒。

二十秒。

手机震动。

**陆时屿："那你愿意做我的最优解吗。"**

没有表情包，没有语气词。句号结尾。

姜晚宁看着那行字，突然笑了出来。

这个人，表白都像在发邮件——措辞精准，格式工整，连标点符号都不带多余的。

她咬了咬下唇，手指悬在键盘上方，故意打了几个字：

**"我考虑一下。"**

发送。

然后她把手机握在手里，靠在椅背上，看着屏幕上那朵还在轻轻摇曳的花。

她想：陆时屿现在一定在看手机。

他一定面无表情，但耳朵一定红了。

他一定在想——"考虑一下"是什么意思？是委婉拒绝还是真的要考虑？如果是真的考虑，那要考虑多久？要不要追问？追问会不会太急？不追问会不会显得不在乎？

她几乎能看到他此刻的样子：坐在工位上，黑框眼镜后面的眼睛盯着手机屏幕，右手无意识地转着笔，大脑飞速运转，试图把"我考虑一下"这四个字解析出八百种可能的含义。

像在debug一段代码。

姜晚宁忍不住笑出声。

一分钟。

她故意等了一分钟。

不多不少，六十秒。

然后她低下头，打了两个字：

**"好。"**

发送。

---

陆时屿坐在工位上，手机屏幕亮着，显示着姜晚宁的对话框。

他看到"我考虑一下"的时候，心跳确实漏了一拍。

理性告诉他：这大概率是女生常用的矜持话术。感性告诉他：万一她真的在考虑呢？

他已经把手指放在键盘上，打了一段话——"没关系，你可以慢慢考虑，我不急"，然后又一个字一个字删掉了。

不急？他急。

他快急死了。

但他不能表现出来。他是陆时屿，他要冷静。

然后，就在他第一百零一次把手指放到键盘上又收回来的时候——

手机震了一下。

**姜晚宁："好。"**

一个字。

陆时屿盯着那个字看了五秒钟。

然后他慢慢摘下眼镜，用手背捂住了眼睛。

旁边工位的周岐探过头来："时屿哥，你怎么了？"

陆时屿把眼镜重新戴上，面无表情地说："没事。"

"你耳朵红了。"

"空调太热。"

"现在五月，开的冷气。"

陆时屿转过头看了他一眼，语气平淡："你今晚的需求文档写完了吗。"

周岐："……告辞。"

陆时屿重新低下头，看着手机屏幕上那个"好"字。

他想了很多种回复方式——

"太好了。"
"我很开心。"
"谢谢。"——不行，太像在回复工作邮件了。

最后他打了四个字：

**"明天见你。"**

发送。

三秒后，回复来了：

**姜晚宁："几点。"**

**陆时屿："你定。"**

**姜晚宁："那你来接我。十点。"**

**陆时屿："好。"**

陆时屿放下手机，重新坐直身体。

屏幕上的代码编辑器还开着，光标在某一行闪闪烁烁。他看了一眼光标的位置，忽然觉得那些字母和符号都不重要了。

他保存文件，关掉编辑器，打开了一个新的Python脚本。

在第一行，他写下注释：

```python
# Date: 2026-05-04
# Note: 今天，我的人生最优解找到了。
```

然后他想了想，又加了一行：

```python
# Status: bug-free. (for the first time in my life)
```

窗外的夜色温柔。

五月的风从没关严的窗缝里溜进来，带着一点花的香气。远处城市的灯光像散落的星子，一盏一盏亮着。

陆时屿靠在椅背上，嘴角弯了一个很小的弧度。

他想起写那朵花的那三个晚上——

第一个晚上，他坐在电脑前，对着贝塞尔曲线的公式发呆。他写过自动驾驶的路径规划，写过传感器数据的滤波算法，写过上万行的仿真代码。但从来没写过一朵花。

他打开数学参考书，一笔一笔地算控制点。花瓣的弧度、花蕊的位置、颜色的渐变——每一个参数都要精确到小数点后四位。

不是因为必须精确。是因为他想做到最好。

就像他说的——这是一个Demo。是他这辈子最重要的一个Demo。

第二个晚上，他删掉了第四个版本，因为花瓣的颜色不够自然。他重新调了渐变参数，把RGB值一个一个改，改到凌晨三点。

第三个晚上，他终于满意了。他反复运行了二十多次，确认花的每一次绽放都完美无瑕。

然后他把代码打包，发给了她。

一百二十七个版本。

他不确定她能不能看懂那些代码里的注释。但他确定，即使她看不懂代码，她也能看懂那朵花。

因为花的语言，不需要编译器。

陆时屿拿起手机，又看了一眼聊天记录。

**姜晚宁："好。"**

一个字。

够了。

第二天早上九点半，陆时屿已经站在姜晚宁公寓楼下。

他穿了一件白色T恤，牛仔裤，没有穿格子衫。

姜晚宁下楼的时候，看到他站在单元门口，手里拿着两杯咖啡。

她走过去，接过咖啡，低头喝了一口。

"几点到的？"她问。

"九点十分。"

"不是说十点吗。"

陆时屿推了推眼镜："提前了一点。"

"提前了五十分钟，叫'一点'？"

他没说话，但耳朵根又红了。

姜晚宁看着他那副面不改色但耳朵出卖一切的样子，忍不住笑了。

"走吧。"她说，率先往前迈了一步。

陆时屿跟上她，两个人并排走在五月的阳光里。

走了大概二十米，姜晚宁突然停下来，转头看着他。

"陆时屿。"

"嗯？"

"你的代码，注释写得很好。"

陆时屿看着她，镜片后面的眼睛很认真："是吗。"

"嗯。"姜晚宁低下头，看着手里的咖啡杯，"尤其是那句——'喜欢你这件事，就是那个无法被优化掉的全局变量。'"

她顿了顿，声音变轻了：

"这句话，我看了三遍。"

陆时屿沉默了一瞬。

然后他说："其实我写了十几版。"

"嗯？"

"那句话。最开始写的是'我对你的感觉是不可约分的分数'，后来觉得太数学了，换成了'你是我的正无穷'，又觉得太俗，最后改成了现在这个版本。"

姜晚宁听得忍不住弯了嘴角："你连写情书都要迭代的吗。"

"嗯。"陆时屿认真地点头，"追求最优解嘛。"

姜晚宁看着他那张一本正经的脸，心里那根绷了好久的弦，终于彻底松开了。

她伸出手，勾住了他的小指。

陆时屿浑身僵了一下，低头看着两个人交缠的手指，耳尖红得快要滴血。

"这……"他张了张嘴。

"这什么这。"姜晚宁没看他，拽着他的手往前走，"你的最优解牵你的手，有什么问题吗。"

陆时屿沉默了三秒。

然后他反手握住了她的手。

五指交扣。

掌心贴着掌心。

他说："没问题。"

五月的阳光洒在两个人身上，把影子拉得很长。

他们手牵着手，走进了那个被算法优化过的、刚刚好的春天。
