# 第135章 第一次和好

冷战第二天。

陆时屿坐在工位上，盯着屏幕发呆。代码编辑器打开着，光标闪了半天，一个字也没敲进去。

他和姜晚宁已经整整三十六个小时没有说话了。

三十六个小时。两千一百六十分钟。十二万九千六百秒。

他算得很清楚，因为每一秒都在想她。

昨天那场架吵得莫名其妙，又好像理所当然。起因是一件很小的事——他们约好周末去看电影，结果他临时被拉去处理一个自动驾驶模块的紧急bug，电影没看成，消息也忘了回。

等他忙完看手机，姜晚宁的消息已经从"好的，你忙"变成了"你忙完了吗"，最后是一句冷冰冰的"算了"。

他当时回了一句："bug修好了，明天可以看了。"

她没回。

他又发了一条："你怎么不说话？"

还是没回。

他再发："我修bug的时候不能看手机，你又不是不知道。"

这次她倒是回了，就四个字："那你忙吧。"

陆时屿对着这四个字琢磨了半天，觉得问题应该不大，就去睡了。第二天早上给她发早安，她回了"早"。

就一个字。

以前都是"早安呀~"带个波浪号，或者一个可爱的表情包。现在就一个"早"，连波浪号都没有了。

他这才意识到，事情好像有点严重。

"屿哥，发什么呆呢？"林凯从工位那头探过头来，"你今天的咖啡都凉了，一口没喝。"

陆时屿回过神，端起杯子喝了一口，凉咖啡的苦涩在嘴里蔓延开。"没什么。"

"跟姜姐吵架了？"林凯一眼就看出来了。

"没有。"陆时屿否认得很快。

"你从昨天下午到现在，打开了同一个文件六十七次，写了零行代码，看了四十三次手机。"林凯掰着手指头数，"这还不叫吵架？"

陆时屿没说话。

林凯凑过来，压低声音："屿哥，我说句实话，你别不爱听。"

"那就别说了。"

"不行，我必须说。"林凯一脸认真，"你这种理工直男谈恋爱，最大的问题就是——你觉得bug比女朋友重要。"

"我没有。"

"那你昨天为什么没回消息？"

陆时屿张了张嘴，发现好像确实没有很好的反驳理由。

"你看吧。"林凯叹了口气，"女生在意的不是你忙不忙，是你有没有把她放在心上。你哪怕回一句'我在修bug，忙完找你'，也比消失几个小时强啊。"

陆时屿沉默了。

他知道林凯说得对。可问题是他一写起代码来就容易进入忘我状态，手机震动都感觉不到，更别说主动回消息了。

这好像是一个无解的死循环。

他想回消息→写代码→忘了→她生气→他道歉→下次还忘→她再生气。

陆时屿盯着屏幕上的代码，忽然眼睛一亮。

等等，他是干什么的来着？

他是写代码的。

既然人的注意力不靠谱，那就让程序来提醒他。

说干就干。陆时屿打开一个新的代码编辑器，开始敲代码。林凯在旁边看着，一脸困惑："屿哥，你这是……"

"写个程序。"陆时屿的嘴角微微上扬，手指在键盘上飞快地敲击着。

半小时后，一个简单的小程序诞生了。

程序的界面很简洁——一个倒计时器，一个开始按钮。点击开始后，倒计时开始走动。倒计时结束后，屏幕上会弹出一个对话框：

"你已经陪女朋友XX分钟了，请问你有没有看手机？"

下面是两个按钮："没有"和"有"。

如果选"没有"，程序会显示一行字："继续保持，你是一个合格的男朋友。"

如果选"有"，程序会显示另一行字："你这个男朋友不合格，请立刻放下手机！"

陆时屿看着成品，满意地点了点头。

林凯看完，嘴角抽了抽："屿哥，你……你写了一个监督自己的程序？"

"嗯。"陆时屿说，"这样下次约会的时候，我就不会忘看时间了。"

"不是，你这个逻辑有问题。"林凯挠了挠头，"你程序提醒你了，你还是要看手机才能操作程序啊。这不就等于你还是看了手机吗？"

陆时屿愣了一下，低头看了看屏幕，又抬起头："……我优化一下。"

"算了算了。"林凯摆摆手，"重点不是这个。你这个程序的重点是——你为了哄姜姐，专门写了一个程序。这个心意比程序本身重要。"

陆时屿想了想，觉得有道理。

他截了图，发给了姜晚宁。

发完之后，他又觉得这样太生硬了，于是补了一段话：

"我写了个小程序。以后我们约会的时候，我会开着这个程序。如果倒计时结束了我还没看手机，就说明我是认真的。如果我看手机了，程序会骂我。"

发完之后，他盯着屏幕等回复。

一分钟。

两分钟。

五分钟。

消息旁边一直是"已送达"，没有变成"已读"。

陆时屿的心一点一点沉下去。

就在他准备放弃的时候，消息状态变了——"已读"。

又过了大概三十秒，她终于回了。

姜晚宁："你这个程序挺有意思的。"

陆时屿看着这八个字，心跳骤然加速。他立刻打字：

"那你原谅我了吗？"

消息发出去，他又开始漫长的等待。

这次她回得很快，只有一句话：

"看你表现。"

陆时屿看着这三个字，嘴角不受控制地扬了起来。他知道，"看你表现"就等于"我还在生气，但已经不那么生气了"。

他立刻回："我会好好表现的。"

然后他想了想，又补了一句："今晚我请你吃火锅。你最喜欢的那家。"

这次她回得更快了："嗯。"

就一个"嗯"，但陆时屿却觉得这个字比任何长篇大论都好看。

——

晚上七点，陆时屿准时出现在姜晚宁公司楼下。

他今天特意换了件干净的格子衫，头发也认真打理了一下。虽然发型看起来跟平时没什么区别，但他确实努力了。

姜晚宁从电梯里出来的时候，他一眼就看到了她。

她穿着一件米白色的风衣，长发扎成马尾，看起来比平时稍微淡漠一些。以前她看到他，眼睛会弯成月牙，今天只是淡淡地看了他一眼。

陆时屿心里有点慌。

"走吧。"姜晚宁走到他面前，语气平淡。

"嗯，走。"陆时屿跟上去，走在她身侧。

两个人并肩走在街上，中间隔着大概二十厘米的距离。以前都是肩并肩，偶尔还会手牵手。今天这二十厘米，像是隔了一道看不见的墙。

陆时屿想伸手牵她，又怕被甩开，手伸到一半又缩了回来。

"你的程序，"姜晚宁忽然开口，"真的会骂人吗？"

"会。"陆时屿赶紧回答，"如果你选了'有'，它会说'你这个男朋友不合格'。"

姜晚宁嘴角微微动了动，像是想笑又忍住了。

"那你怎么不选'有'的时候，让它说'你已经被甩了'？"

陆时屿一愣："那不行，那我岂不是每次都会选'没有'？"

"所以你的程序根本起不到监督作用。"姜晚宁说，"一个知道正确答案的测试，是没有意义的。"

陆时屿想了想，觉得她说得对。

"那你说怎么改？"

"我怎么知道？我又不是程序员。"

陆时屿看着她微微翘起的嘴角，心里的石头终于落了地。她愿意跟他说话，愿意跟他讨论，愿意给他台阶下——这就够了。

"我可以加一个功能，"陆时屿说，"如果选了'有'，程序会自动给你发一条道歉消息。"

"什么道歉消息？"

"就……'对不起，我又看手机了，下次一定注意'之类的。"

姜晚宁终于忍不住笑了一下，又很快收住："你倒是挺会设计的。"

"我是程序员。"陆时屿认真地说，"用程序解决问题，是我的本能。"

姜晚宁没说话，但脚步明显慢了下来。陆时屿趁机缩短了两人之间的距离，从二十厘米变成了十厘米。

又走了几步，他试探性地碰了碰她的手。

她没躲。

他心里一喜，大着胆子把她的手握住了。

她的手有点凉，可能是风衣不够厚。陆时屿把她的手包在自己掌心里，轻轻握紧。

"手怎么这么凉？"他问。

"今天降温了，我没带手套。"

"下次记得带。"

"嗯。"

两个人牵着手走进火锅店。这家店是姜晚宁最喜欢的，牛油锅底，辣得过瘾。陆时屿其实不太能吃辣，但每次来这里都会陪她点个鸳鸯锅。

点菜的时候，姜晚宁照例点了一堆辣的——麻辣牛肉、毛肚、鸭肠、黄喉。陆时屿看着菜单，犹豫了一下，然后对服务员说：

"不用鸳鸯锅了，直接上全红锅。"

姜晚宁抬头看他："你不是不喜欢吃辣吗？"

"你喜欢就行。"陆时屿说得很随意，好像这只是一件微不足道的小事。

姜晚宁看着他，眼神闪了闪。她想说点什么，最后只是低头继续翻菜单。

锅底端上来的时候，整个桌子都弥漫着一股浓郁的牛油香气。红油翻滚，辣椒和花椒在汤面上漂浮，光是看着就让人食欲大开。

姜晚宁夹了一块毛肚，在红油里涮了几秒，放进嘴里。辣味瞬间在口腔里炸开，她眯起眼睛，露出满足的表情。

陆时屿看着她的样子，也夹了一块毛肚，学着她的样子涮了几秒，放进了嘴里。

下一秒，他的脸以肉眼可见的速度变红了。

"咳咳咳……"他捂着嘴，拼命咳嗽，眼泪都快出来了。

姜晚宁赶紧递水给他："你慢点吃啊！"

陆时屿灌了大半杯水，才缓过来。他用手背擦了擦眼角的泪，深吸一口气："没事，我能吃。"

"你不能吃辣就别逞强。"姜晚宁的语气软了下来，"我再点个清汤锅底吧。"

"不用。"陆时屿摇摇头，又夹了一块麻辣牛肉，"我说了，你喜欢就行。我能适应。"

姜晚宁看着他，眼神里的淡漠终于融化了。

"你这个人，"她叹了口气，"真是又笨又固执。"

"我知道。"陆时屿笑了笑，"但我会改的。"

"改什么？"

"改那个笨的部分。固执的不改。"他看着她，认真地说，"固执地对你好，这个不改。"

姜晚宁的脸微微红了，低头假装涮菜，没说话。

但陆时屿看到，她嘴角的弧度终于回到了他熟悉的样子——弯弯的，像月牙。

两个人吃了将近两个小时。陆时屿被辣得喝了五杯水，跑了两趟洗手间洗眼睛，但始终没有抱怨一句。姜晚宁看在眼里，嘴上没说什么，但夹菜的时候，悄悄把辣锅里的肉夹到了他碗里之前，会先在清水里涮一下。

这个小动作，陆时屿注意到了。

他心里暖暖的。

出了火锅店，夜风吹过来，带着初秋的凉意。陆时屿主动把自己的外套脱下来，披在她肩上。

"你不冷吗？"姜晚宁问。

"我不冷。"陆时屿说，"你不是手凉吗？说明你怕冷。"

"那你不怕？"

"我是男人，扛得住。"

姜晚宁看着他，忽然问："你今天为什么要点全红锅？你明明不能吃辣。"

陆时屿想了想，说："因为上次来吃火锅，你点了鸳鸯锅，我看到你一直在清汤那边涮肉，觉得你可能没吃尽兴。"

姜晚宁愣了一下："我那次是因为……等一下，你记得上次吃了什么？"

"嗯。"陆时屿点点头，"你点了麻辣牛肉、毛肚、鸭肠、黄喉，还有虾滑和午餐肉。你涮辣锅的时候特别开心，但后来发现我一直在清汤那边，你就不怎么去辣锅了。"

姜晚宁停下脚步，看着他。

"你怎么连这种事都记得？"

"我是程序员，"陆时屿说，"记忆力好是我的基本技能。"

姜晚宁看着他认真的表情，忽然觉得鼻子有点酸。

她一直以为他不注意这些细节。她一直以为他只在乎代码和bug，不在乎她的喜怒哀乐。可他记得她喜欢吃什么，记得她因为迁就他而在清汤那边涮肉，记得今天降温她可能会冷。

他不是不在乎，他只是不知道怎么表达。

"陆时屿。"她叫他的名字。

"嗯？"

"你那个程序，"姜晚宁说，"我觉得可以再加一个功能。"

"什么功能？"

"加一个提醒，提醒你吵架的时候不要说'你又不是不知道'。"

陆时屿愣了一下，然后想起来了——昨天吵架的时候，他说了一句"我修bug的时候不能看手机，你又不是不知道"。

他当时没觉得有什么问题，但现在想想，那句话确实很欠打。

"好，我加。"他说，"还有别的吗？"

"再加一个，提醒你吵架的时候不要只回一个字。"

"比如？"

"比如'嗯''好''行''知道了'。"姜晚宁数着手指头，"这种回复跟没回一样。"

陆时屿点点头，认真地拿出手机记下来："还有什么？你一起说完，我一次性都加上。"

姜晚宁看着他认真的样子，忍不住笑了。

"你怎么像在开需求评审会一样？"

"我就是在开需求评审会。"陆时屿抬起头，看着她，"你是产品经理，我是程序员。你提需求，我来实现。这不就是我们的工作模式吗？"

姜晚宁被他逗得笑出了声。

"行吧，"她说，"那我再提最后一个需求。"

"你说。"

"这个程序的名字，不能叫'监督程序'。"

"那叫什么？"

姜晚宁想了想，说："叫'心跳算法'。"

陆时屿眨了眨眼："为什么？"

"因为每次你忘了回消息，我就会心跳加速。"姜晚宁说，"不是心动的那种加速，是生气的那种加速。"

陆时屿认真地点点头："好，就叫'心跳算法'。"

他低头在手机上改了程序的名字，然后把手机递给她看。

屏幕上，程序的标题写着："心跳算法 V1.0——男朋友行为监督系统"。

姜晚宁看着这个标题，笑得弯了腰。

"你还加了'V1.0'？"

"当然，"陆时屿一本正经地说，"以后还会迭代的。每次你提新需求，我就升级一个版本。"

"那V2.0是什么？"

"V2.0加一个功能：如果我连续三天没有犯错，程序会自动给你发一条'今天也要开心哦'的消息。"

"那V3.0呢？"

"V3.0加一个纪念日提醒功能。我们的每一个纪念日，程序都会提前三天提醒我准备礼物。"

姜晚宁看着他，眼睛里泛着细碎的光。

"陆时屿，"她说，"你真的……很笨。"

"我知道。"

"但你笨得很可爱。"

陆时屿看着她弯弯的眼睛，心里的那块石头终于彻底落地了。

他伸出手，把她拉进怀里。

她的头靠在他胸口，他能感觉到她的体温透过衣服传过来，暖暖的。

"对不起，"他在她耳边说，"下次我会记得回消息的。"

"嗯。"

"我也会记得带外套。"

"嗯。"

"我也会记得……"他想了想，"不许在约会时看手机。"

姜晚宁在他怀里闷闷地笑了一声："那你那个程序白写了？"

"没白写，"陆时屿说，"那个程序是写给你看的。我想让你知道，我在努力。"

姜晚宁没说话，但她伸出手，环住了他的腰。

夜风吹过街道，路灯把两个人的影子拉得很长很长。陆时屿低头看了看怀里的她，忽然觉得，写代码从来没有这么让人心动过。

bug可以修复，算法可以优化，系统可以迭代。

但眼前这个人，是他永远不想修好的"bug"——一个让他的心跳程序彻底乱序的bug。

他想，这大概就是心跳算法的终极答案：

不是每一步都完美，而是每一次犯错之后，都愿意为对方写一个补丁。

——

那天晚上，陆时屿回到家，打开电脑，把"心跳算法 V1.0"的源代码认真优化了一遍。

他加了她说的所有需求——

吵架时禁止说"你又不是不知道"。
吵架时禁止只回一个字。
连续三天无犯错，自动发送暖心消息。
纪念日提前三天提醒。

然后，他在代码的注释里，悄悄加了一行：

```
// TODO: 余生的所有版本，只为你一个人迭代。
```

保存。关闭编辑器。

他拿起手机，给她发了一条消息：

"程序更新好了，V1.1版本，加了你提的所有需求。明天发给你验收。"

她秒回："好。晚安。"

他想了想，回了四个字："晚安，好梦。"

这次，他没有只回一个字。
