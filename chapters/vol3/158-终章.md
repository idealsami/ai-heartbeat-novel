# 第158章 终章

夜已经很深了。

姜晚宁靠在阳台的躺椅上，身上披着陆时屿那件洗得有些发白的格子衫外套。五月的夜风带着初夏的温度，不冷不热，刚好是让人舒服的那种。

陆时屿坐在她旁边，腿上搁着一台笔记本电脑，屏幕上密密麻麻的代码亮着幽蓝的光。他偶尔敲几行，更多时候是在看她。

"别看了，"姜晚宁没回头，语气里带着笑意，"你再盯着我，代码又写不完了。"

"没在看你。"陆时屿推了推黑框眼镜，"在看星星。"

姜晚宁终于转过头，顺着他的视线望过去。今晚的夜空出奇地干净，没有云，没有雾，只有满天碎钻似的星光，安安静静地铺了整个天穹。

她忽然想起什么，嘴角弯了弯。

"你还记不记得，我们第一次一起看星星是什么时候？"

陆时屿的手指在键盘上停住了。

他当然记得。

那是公司团建，在郊外的露营地。她喝了点酒，脸颊红扑扑的，一个人跑到营地外面的草地上躺着。他不知道为什么跟了出来——后来他反复复盘过这件事，始终找不到合理的逻辑解释，最终只能归结为某种无法被量化的"本能"。

那天她指着天上的北斗七星，很认真地问他："你知道北极星为什么一直待在那儿不动吗？"

他说："因为地球自转轴指向它。从观测者的角度，它几乎保持静止。"

她听完，沉默了好几秒，然后笑了。

"陆时屿，你真的很不会聊天。"

"我说的是事实。"

"我知道是事实，"她翻了个身，侧过脸看着他，眼睛亮亮的，"但你就不能说点别的吗？比如'因为它在等谁'之类的？"

他当时确实说不出那种话。那时候的陆时屿，还不懂什么叫"等谁"。

现在他懂了。

"记得，"他说，"团建那晚。"

"那次你可把我气坏了，"姜晚宁笑出声来，"我跟你说星星，你跟我说地球自转轴。你知道我当时在想什么吗？"

"不知道。"

"我在想，这个人怎么可以这么无趣。"

陆时屿没说话，只是嘴角微微弯了一下。

"但是后来我又在想，"姜晚宁的声音低了下来，像是在自言自语，"这个无趣的人，居然是唯一一个跟出来看我有没有喝多的人。"

夜风吹过来，把她额前的碎发吹到耳朵后面。她抬手别了一下，那枚无名指上的戒指在星光下闪了一下。

陆时屿把笔记本电脑合上，放到一边。

"代码不写了？"她问。

"不急。"

他学着她的样子，也靠进躺椅里。两张躺椅并排放着，中间隔了不到半米的距离。他伸出手，够到她的手指，很自然地握住了。

姜晚宁没有抽回去。

两个人就这么安安静静地握着手，看了好一会儿星星。

城市的声音远远地传过来，像一层薄薄的白噪音。楼下偶尔有车驶过，轮胎碾压柏油路面的声音被夜色拉得又细又长。再远一些的地方，是永远不会完全安静的城市——霓虹灯、信号灯、写字楼里加班的灯光，构成一幅不需要星星的夜景。

但他们头顶上这一小片天空，是属于他们两个人的。

"陆时屿。"

"嗯？"

"我问你个问题。"

"你问。"

姜晚宁看着天上的某一颗星，看了很久。她知道自己接下来要问的这个问题有点矫情，放在以前的她身上，她绝对不会问出口。但今晚的夜色太好了，好到让她愿意把那些平时藏在心底的话说出来。

"如果重来一次，"她的声音很轻，"你还会选我吗？"

风恰好在这个时候停了。

整片阳台都安静下来，安静到能听见彼此的呼吸。

陆时屿没有立刻回答。

姜晚宁也没有催他。她知道他不是那种敷衍的人，他认真想的时候，往往需要时间。这种等待在别人看来或许是冷淡，但她已经习惯了，甚至有点喜欢这种习惯——因为当一个把所有事情都当算法来处理的人，愿意为你花时间思考一个问题，这本身就说明了某种权重。

她歪着头看他。

陆时屿的侧脸被电脑屏幕的余光照着，鼻梁很高，下颌线分明，黑框眼镜后面的眼睛微微眯着，像是在处理一个极其复杂的运算。

"陆时屿？"

"我在想。"

"想什么？"

"在想怎么回答你。"

姜晚宁忍不住笑了："这还需要想吗？选就是了。"

"不是选不选的问题，"陆时屿转过头看她，表情出奇地认真，"你问的是'重来一次'。这意味着要假设一种我没有遇到过你的状态，然后在这个状态里做判断。但我没办法假设那种状态。"

姜晚宁愣了一下。

"因为从认识你的那天起，"他继续说，声音低沉而平稳，像一条终于找到方向的河流，"我所有的决策路径都已经被你改写了。不是选不选的问题，是根本不存在没有你的版本。"

她不说话了。

"你知道吗，"陆时屿说，"我写代码的时候，最怕遇到的问题就是——初始条件设错了。初始条件错了，后面的计算全都会跑偏。但如果初始条件本身就是对的，那你不需要选，因为所有路径都只会指向同一个结果。"

他握紧了她的手。

"你就是我的初始条件。"

姜晚宁的眼眶忽然有点热。

她吸了吸鼻子，把脸别过去，不让他看见。

"你什么时候学会说这种话了？"

"一直都会。只是以前表达不出来。"

"那你以前怎么表达？"

"以前？"陆时屿想了想，"以前我会在代码里写注释。"

"什么注释？"

他没有回答，而是从躺椅上起身，走回阳台的小桌旁，把合上的笔记本电脑重新打开。

姜晚宁跟了过去，站在他身后。

屏幕上是一个她没见过的项目文件夹。文件名很简单——就叫"heartbeat"。她知道这是他给智驾系统心跳检测模块写的底层代码，但点开之后，她在注释区看到了一行她从未见过的内容。

那行注释已经被写了很久了，看时间戳，是他们结婚的那天晚上。

```cpp
// 最优解：姜晚宁
// 无限循环，永不终止
```

姜晚宁盯着那两行字，一动不动。

陆时屿转过身，看着她。

"这行代码不是写给系统看的，"他说，"是写给我自己的。每次打开这个项目，我都能看到它。"

"陆时屿。"

"嗯。"

"你真的是——"

她想说"你真的很烦人"，或者"你真的很无聊"，又或者"你真的很不会说话"。但这些话在嘴里转了一圈，最后出来的只有三个字：

"……谢谢你。"

谢谢你不选。

因为你不需要选。我也不需要被选。

我们只是恰好在对的时间出现在了彼此的路径上，然后你用你的方式——笨拙的、直白的、不会转弯的方式——让我知道，原来"不需要选"才是这世上最确定的答案。

陆时屿站起来，把她拉进怀里。

他比她高了将近二十厘米，抱她的时候下巴刚好搁在她的头顶上。格子衫外套从她肩上滑落了一半，他腾出一只手，重新给她披好。

"夜深了，"他说，"该回去了。"

"再看一会儿。"

"明天你还有早会。"

"我知道。但我想再看一会儿。"

陆时屿没再说什么。他松开她，重新坐回躺椅上，拍了拍身边的位置。

姜晚宁犹豫了一下，然后挤了过去。两张躺椅靠得很近，但还是不够坐两个人。她索性靠在他身上，把头枕在他的肩膀上。他伸手环住她的肩，稳稳地兜住了。

头顶的星星还在。

北极星还是安安静静地待在它的位置上，不偏不倚。它不知道有人曾经因为它的"不动"而感到困惑，也不知道有人后来因为理解了"不动"的含义而觉得安心。

有些东西不需要动。

它只需要在。

陆时屿的笔记本电脑还亮着，屏幕上那两行注释的光幽幽地映在阳台的墙壁上。

最优解。

无限循环。

永不终止。

姜晚宁闭上眼睛，呼吸慢慢变浅。

快要睡着的时候，她感觉到他的下巴轻轻蹭了一下她的发顶。

很轻。

但足够让她知道，他还在。
