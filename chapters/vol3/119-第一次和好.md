# 第119章 第一次和好

陆时屿盯着屏幕上的代码看了整整三个小时。

不是在写自动驾驶的感知算法，也不是在调BEV特征提取的参数，而是在写一个……道歉程序。

确切地说，是一个提醒自己"不许在约会时看手机"的小程序。

起因是昨晚那场吵架。

——或者说，是姜晚宁单方面宣布"我不想理你"之后，长达二十六小时的冷战。

陆时屿摘下黑框眼镜，揉了揉酸涩的眼睛。电脑右下角的时间显示晚上九点四十七分，办公区已经空了大半，只有几个加班的同事还在工位上敲键盘。

他点开微信，姜晚宁的对话框还停留在昨天下午。

最后一条消息是他发的："你在哪？我去接你。"

已读，没有回复。

再往上翻，是她发的那条消息："陆时屿，你是不是觉得手机比我还重要？"

这句话的起因，是前天的约会。

他们约好去看电影，结果电影开场前他就接到了同事的电话，讨论一个感知模块的bug。他一边讲电话一边跟她进了影厅，电影放到一半他还在低头回消息。

姜晚宁全程没有说话。

电影结束后她只说了一句"我先回去了"，然后头也不回地走了。

陆时屿后知后觉地意识到自己犯了多大的错误。

他重新戴上眼镜，看着屏幕上写了大半的程序。代码的语言是Python，他用Tkinter做了一个简单的GUI界面，逻辑很简单，也很"陆时屿"——

用程序解决情感问题。

他又改了几行代码，调试了两遍，确认没有bug之后，截了个图。

然后他打开微信，犹豫了三秒钟，把截图发了过去。

---

姜晚宁收到消息的时候，正窝在沙发上看综艺。

手机震了一下，她瞥了一眼，是陆时屿发的图片。她本想忽略，但手指还是不由自主地点开了。

那是一张程序运行的截图。

界面很朴素，白底黑字，左上角甚至还有Windows默认的标题栏。程序名叫"约会守护.exe"，运行之后，屏幕上弹出了一个倒计时——

**02:15:33**

倒计时下方有一行注释："这是你和女朋友已经在一起的时间，单位：分:秒。"

再下方，倒计时结束之后会弹出一个对话框，对话框里的文字清清楚楚：

**"你已经陪女朋友135分钟了，请问你有没有看手机？"**

下面是两个按钮。

左边的按钮写着"没有"，右边的按钮写着"有"。

姜晚宁的嘴角微微动了一下。

她继续往下看截图。

选了"没有"之后，程序会弹出一个新的窗口，上面写着：**"继续保持！你是一个合格的男朋友！"**，后面还跟了一个程序员手打的颜文字：(｡♥‿♥｡)

选了"有"之后，程序弹出的是：**"你这个男朋友不合格！！！请立刻放下手机！！！"**，颜文字变成了：(╬▔皿▔)

截图的最下方，陆时屿还附了一段代码注释：

```python
# 陆时屿专属约会自律程序 v1.0
# 作者：陆时屿
# 创建日期：2026年5月4日
# 版本说明：此程序用于监督陆时屿在约会期间不玩手机
# 如果违反规定，程序会自动扣除陆时屿的"好男友积分"（初始值为100）
# 积分低于60分时，系统将自动发送道歉短信给姜晚宁
# 备注：这个程序只有一次机会，请务必珍惜
```

姜晚宁盯着屏幕看了很久。

然后，她笑了。

不是那种礼貌性的微笑，是真的被逗到了。她甚至笑出了声，综艺里的笑声和她的笑声混在一起，在空荡荡的客厅里回荡。

她把截图放大又看了一遍，注意到程序角落里还有一个小细节——倒计时的旁边，画了一个小小的爱心，用字符拼的：

```
  ♥
 ♥♥♥
♥♥♥♥♥
 ♥♥♥
  ♥
```

笨拙，粗糙，但是……很陆时屿。

姜晚宁抿着嘴，打了一行字："你这个程序挺有意思的。"

发送。

然后她放下手机，继续看综艺，假装自己很淡定。

手机几乎是在她放下的一瞬间就震了。

陆时屿回得很快："那你原谅我了吗？"

姜晚宁看着这行字，能想象到他此刻的表情——一定是那副认真到有点呆的样子，黑框眼镜后面的眼睛微微瞪大，像一个等待老师打分的学生。

她故意等了两分钟才回："看你表现。"

回复发出后，她忍不住又看了一眼那个程序截图，嘴角的弧度怎么也压不下去。

陆时屿的回复在三秒后弹出来："我会好好表现的。"

紧接着又是一条："今天晚上有空吗？"

姜晚宁犹豫了一下，打了两个字："干嘛？"

"我带你去吃火锅。你上次说想吃的那家，就是排号特别长的那家。"

"你不是不吃辣吗？"

"你喜欢就行。"

姜晚宁盯着这四个字看了好一会儿。

窗外的夜色已经完全暗了下来，路灯的光透过窗帘缝隙洒进来，在手机屏幕上折射出淡淡的光晕。她忽然觉得鼻子有点酸，不是因为委屈，是因为——

这个理工直男，真的在用自己的方式努力。

"行。"她回了一个字。

"我来接你，二十分钟到。"

---

陆时屿到姜晚宁楼下的时候，计时器显示十八分钟。

他把车停好，看了一眼副驾驶座位上放着的东西——一杯姜晚宁最爱的芋泥波波奶茶，三分糖，加椰果。

这是他下午特意去买的，跑了三家店才找到她常喝的那家。

他推开车门，抬头往上看了一眼。姜晚宁住的那层亮着灯，窗帘上映出一个模糊的影子。

他发了条消息："我到了。"

一分钟后，单元门打开了。

姜晚宁走出来的时候，陆时屿的目光不由自主地停住了。

她今天穿了一件奶白色的针织开衫，里面是浅蓝色的连衣裙，长发扎成了高马尾，耳朵上戴了一对很小的珍珠耳钉。不是平时在公司里那种雷厉风行的产品经理打扮，多了几分……温柔？

陆时屿不确定这个词用得对不对，但他觉得很好看。

"你干嘛一直看我？"姜晚宁走到车前，瞥了他一眼。

"你今天很好看。"陆时屿很直接地说。

姜晚宁的耳尖微微红了一下，但脸上还是那副淡淡的表情："上车吧，我饿了。"

陆时屿拉开副驾驶的门，姜晚宁弯腰坐进去，一眼就看到了座位上的奶茶。

她愣了一下。

"三分糖，加椰果。"陆时屿从另一边上了车，系好安全带，"你上次说的那家店，我跑了三家才找到。"

姜晚宁拿起奶茶，吸管戳进去，喝了一口。

温度刚好，甜度刚好，椰果的量也刚好。

她没有说谢谢，但嘴角的弧度出卖了她。

陆时屿发动了车子。导航显示到那家火锅店还有二十分钟车程，他没有看手机，双手稳稳地握着方向盘。

车里放着音乐，是他歌单里的歌，旋律舒缓。姜晚宁靠在椅背上，偶尔喝一口奶茶，偶尔看一眼窗外的街景。

谁都没有提前天的争吵。

有些事情，不需要解释太多。一个程序，一杯奶茶，一句"你喜欢就行"，就已经够了。

---

火锅店果然排了很长的队。

陆时屿提前在手机上取了号，到了之后只等了十几分钟就有位置了。服务员把他们带到一个靠窗的双人桌，桌面中间是翻滚的红油锅底，辣椒和花椒在汤面上漂浮，香气扑鼻。

"你点吧。"陆时屿把菜单推给姜晚宁。

姜晚宁也不客气，噼里啪啦点了一堆：毛肚、黄喉、鸭肠、虾滑、嫩牛肉、鲜鸭血，还有她最爱的酥肉。

"你够吃吗？"她抬头问。

"够了。"陆时屿看了一眼菜单，又加了一份土豆和一份娃娃菜，"你不是爱吃这两样吗？"

姜晚宁的动作顿了一下。

她确实爱吃，但那只是很久以前随口提过一次。

"你记得？"

"记得。"陆时屿推了推黑框眼镜，语气很平淡，像是在陈述一个不需要解释的事实，"你上次吃火锅的时候说，没有土豆和娃娃菜的火锅没有灵魂。"

姜晚宁低下头，假装在研究菜单，实际上是在掩饰自己微微发烫的耳朵。

这个男人。

总是在一些奇怪的地方记性特别好。

锅底开了，热气蒸腾。陆时屿开始往锅里下菜，手法有些生疏——他是真的不怎么吃辣，上次陪姜晚宁吃火锅，辣得喝了三瓶水，第二天嗓子就哑了。

但他今天什么都没说，安安静静地涮菜，把毛肚七上八下烫好之后，夹到了姜晚宁的碗里。

"你的。"

"你不吃？"

"我不太饿。"

姜晚宁看了他一眼。他的耳根有些红，不知道是因为热气还是因为辣。

她夹了一筷子鸭肠，在锅里涮了几秒，放进他碗里。

"你也吃。"

陆时屿低头看着碗里的鸭肠，上面裹满了红油。他犹豫了一下，还是夹起来放进了嘴里。

一秒。

两秒。

三秒。

辣意从舌尖蔓延开来，像是一把火从嘴里烧到了喉咙。陆时屿的脸以肉眼可见的速度变红，他端起水杯猛灌了一口。

姜晚宁看着他的样子，终于忍不住笑出了声。

"你不是说不饿吗？明明就是怕辣。"

陆时屿放下水杯，认真地说："我可以学。"

"学什么？"

"学吃辣。"他的语气很认真，"你喜欢的东西，我不想总是让你一个人。"

姜晚宁的笑声停住了。

火锅店很吵，隔壁桌在划拳，对面的桌子在碰杯，服务员在大声喊号。但她忽然觉得这些声音都变远了，整个世界安静下来，只剩下对面这个人说的话。

"陆时屿。"她放下筷子。

"嗯？"

"你知道你刚才说的话有多肉麻吗？"

陆时屿愣了一下，然后很诚实地回答："我觉得还好，只是在陈述事实。"

姜晚宁忍不住又笑了。

这个人真的是……一点都不会说情话，但是每一句都精准地戳中她。

"行了行了，吃饭。"她重新拿起筷子，往他碗里又夹了一块嫩牛肉，"你也多吃点，光喝水怎么行。"

陆时屿看着碗里的牛肉，认真地点了点头。

这顿火锅吃了将近两个小时。

红油锅底见了三次水，桌上堆满了空盘子。姜晚宁吃得很满足，靠在椅背上摸了摸肚子。

"好撑。"

"还要加菜吗？"

"你是想撑死我吗？"

陆时屿沉默了两秒，然后很认真地说："我不想。"

姜晚宁瞪了他一眼，但眼睛里的笑意藏不住。

结账的时候，两个人同时拿出了手机扫码。陆时屿的手速更快一些，抢在她前面付了款。

"我说了今天请你。"

"那下次我请。"姜晚宁收起手机，"不许跟我抢。"

"好。"

走出火锅店的时候，夜风微凉，吹散了身上沾的火锅味。姜晚宁缩了缩脖子，陆时屿很自然地脱下外套，披在了她肩上。

外套还带着他的体温，暖烘烘的。

两个人沿着街道慢慢走着，路灯把他们的影子拉得很长。

"陆时屿。"姜晚宁忽然开口。

"嗯？"

"你那个程序……"她顿了顿，"是真的能用的吗？"

"能用。"陆时屿从口袋里掏出手机，打开了一个应用，"我已经装在手机上了。下次约会的时候，我会提前运行这个程序。如果我碰手机超过十秒钟，它就会自动弹窗提醒我。"

姜晚宁凑过去看了一眼，屏幕上是一个简洁的界面，倒计时正在运行——

**00:03:27**

"现在也在计时？"她问。

"对。"陆时屿看着她，镜片后面的眼睛里倒映着路灯的光，"从你出来的那一刻就开始计了。"

姜晚宁看着那个不断跳动的数字，心里忽然涌起一股说不清的感觉。

这个人明明不会甜言蜜语，明明笨拙得要命，但他做的每一件事，都带着一种笨拙的真诚。

像他写的代码一样，一行一行，没有多余的花哨，但每一行都在认真运行。

"陆时屿。"她又叫了一声他的名字。

"嗯。"

"我原谅你了。"

陆时屿的脚步停了。

他转过头看着她，路灯的光打在她脸上，马尾被风吹得微微晃动，眼睛里带着笑意。

他想说点什么，但张了张嘴，最后只说了两个字："谢谢。"

姜晚宁噗嗤一声笑出来："你跟女朋友说谢谢？"

"那……"陆时屿想了想，很认真地更正，"谢谢你愿意原谅我，我以后会做得更好。"

"行了行了。"姜晚宁摆摆手，转身继续往前走，"别光嘴上说，拿出你的程序来证明。"

陆时屿跟上去，两个人并肩走在路灯下。

他偷偷看了她一眼，她的嘴角是弯的。

他又低头看了一眼手机，倒计时已经跳到了——

**00:05:12**

五分十二秒，没有看手机。

陆时屿收起手机，把手伸进口袋里，指尖碰到了口袋里那张写满代码的便签纸。上面是他昨天晚上写的一句话，准备用来当程序的启动画面，但最后没有加上去——

**"这个世界上最难的bug，是你生气的时候我不知道怎么哄你。但我会一直调试，直到程序跑通为止。"**

他想，也许下次可以给她看。

也许不用。

有些话，不说出来，她也知道。

---

到了姜晚宁楼下，两个人站在单元门前。

夜风又吹过来，这次更大了一些。姜晚宁把外套脱下来还给他，陆时屿接过来，却没有穿上。

"上去吧。"他说，"早点休息。"

"嗯。"姜晚宁转身走向单元门，走了两步又停下来，回头看了他一眼。

"陆时屿。"

"嗯？"

"下次约会，"她顿了顿，嘴角微微上扬，"你那个程序，记得提前运行。"

陆时屿点了点头："会的。"

"还有，"姜晚宁的声音轻了一些，"……路上注意安全。"

她说完就转身进了单元门，步伐比平时快了一些。

陆时屿站在原地，看着她的身影消失在门后，听着楼道里的脚步声一层一层往上。

他低头看了一眼手机，程序的倒计时停在了——

**00:23:41**

二十三分四十一秒。

全程没有碰手机。

他把外套搭在手臂上，转身走向停车场。夜风把他的格子衫吹得鼓起来，他忽然觉得，今天的风，好像没有那么凉。

上车之后，他做的第一件事，是打开那个程序，在"有没有看手机"的选项上，点了"没有"。

屏幕上弹出一行字——

**"继续保持！你是一个合格的男朋友！"**

后面跟着一个手打的爱心。

陆时屿看着那个爱心，嘴角弯了一下。

很浅，但是很真。

他发动了车子，驶入夜色中。

后视镜里，姜晚宁家的灯亮着。

他想，明天上班的时候，可以再给程序加一个功能——每天提醒他跟她说早安和晚安。

毕竟，作为一个算法工程师，他最擅长的事情，就是让程序不断迭代，变得更好。

而作为一个男朋友，他也想这样做。

**——第119章 完——**
