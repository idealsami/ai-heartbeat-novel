# 第230章 最后的代码

夜深了。

陆时屿坐在书房里，面前的电脑屏幕散发着淡淡的蓝光，映在他棱角分明的脸上，像是一层薄薄的霜。

他已经很久没有写代码了。

自从卸任了HeartBeat科技的CTO职务，他把大部分时间都留给了姜晚宁和两个孩子。公司的事交给了沈渡打理，他偶尔去开个会，签个字，其余时间便在家陪她种花、做饭、散步——过一种他从前以为永远不会属于自己的生活。

邻居们都说，陆时屿变了。

从前那个凌晨三点还在群里发技术文档的男人，现在会在傍晚六点准时出现在厨房里，系着围裙，研究新菜谱。从前那个开会时面无表情、让人不敢靠近的陆总，现在会在小区花园里蹲下身子，认真地帮女儿系好松开的鞋带。

但今晚不同。

他把手指放在键盘上，停了很久。

桌角放着一杯已经凉透的咖啡，窗外是五月的夜风，带着院子里蔷薇花的香气。二楼卧室的灯早就灭了，姜晚宁应该已经睡了——她最近总说累，他便催她早睡，自己却在书房里坐到了凌晨一点。

不是失眠。

是有些话，他想了二十年，终于想好要怎么说。

---

陆时屿从五岁开始学编程。

那时候他父亲陆恒远给他买了一台二手电脑，灰色的机箱，CRT显示器，开机时发出嗡嗡的电流声。别的孩子在院子里追跑打闹的时候，他坐在那台电脑前，一行一行地敲着最简单的print语句。

"Hello, World."

那是他写的第一行代码。屏幕上跳出这两个单词的时候，他感到了一种奇异的满足——仿佛他终于找到了一种方式，可以和这个世界对话。

他父亲站在他身后，看了很久，说了一句："这孩子，以后了不得。"

后来他学会了很多。数据结构、算法、操作系统、分布式系统……他写的代码越来越多，越来越复杂，也越来越大。他创办HeartBeat科技的时候，亲手写下了第一版推荐算法的全部代码，几十万行，一行一行地调试、优化、重构，直到它能精准地理解每一个用户的"心跳"。

那些代码让他成名，让他站在了技术世界的顶端。

但代价是什么？

是无数个失眠的夜晚，是连续三天不洗澡的狼狈，是把咖啡当水喝的麻木，是面对崩溃的服务器时冷到发抖的手指，是一个人坐在空荡荡的办公室里，盯着屏幕上的报错信息，想不出任何解决办法的绝望。

他曾经以为，代码就是他生命的全部。

直到他遇见了姜晚宁。

但此刻，他想写的不是那些商业代码、系统代码、算法代码。

他想写一段最简单的代码。

简单到只需要一个变量，一个循环，一个输出。

就像他五岁时写的那个Hello World一样简单。

---

姜晚宁翻了个身。

身边的位置是空的，被子还留着一点余温，但人已经不在了。她迷迷糊糊地伸手摸了摸，睁开眼睛，看见卧室门缝下透进来一线微光。

她叹了口气，披了件外套，赤着脚下楼。

走廊里很安静，只有墙上挂钟的秒针在走。滴答、滴答，一声一声，像是在替这个家数着什么。她走到书房门口，透过半掩的门，看见陆时屿坐在电脑前的背影。

他的脊背微微弯着，肩膀的线条在灯光下显得格外清晰。手指在键盘上敲击着，节奏不快，像是在思考每一行代码该不该落下。

姜晚宁靠在门框上，没有出声。

她看了他很久。

这个男人，她认识了二十二年，嫁给了他十几年。她见过他意气风发地站在发布会上，见过他连续三天不睡觉修复服务器故障，见过他在会议室里拍桌子骂人，也见过他抱着女儿在阳台上看夕阳时眼底的温柔。

但此刻的陆时屿，是她从未见过的样子。

安静。专注。像是在写一封很长很长的情书。

---

陆时屿没有发现她。

他全神贯注地盯着屏幕，手指时而飞速敲击，时而停下来，在键盘边缘轻轻敲两下——那是他思考时的习惯动作，二十年了，一直没有改掉。

屏幕上的代码并不复杂。他没有用任何花哨的框架，没有调用任何第三方库，只用了最基础的Python语法，写了一个最朴素的类。

```python
import time

class Love:
    def __init__(self, start="2004"):
        self.partner = "姜晚宁"
        self.start = start
        self.memory = []
        self.state = "eternal"
    
    def heartbeat(self):
        while True:
            self.memory.append(self.partner)
            yield f"想你：第{len(self.memory)}次"
    
    def optimal_solution(self, universe):
        candidates = universe.search_all()
        result = None
        for person in candidates:
            if person == self.partner:
                result = person
                break
        # 如果遍历整个宇宙都找不到，就创造一个新的
        if result is None:
            result = self.partner
        return result
    
    def run(self):
        print("=" * 40)
        print("  陆时屿的人生最优解")
        print("=" * 40)
        
        universe = "all"
        answer = self.optimal_solution(universe)
        
        print(f"\n  搜索范围：整个宇宙")
        print(f"  算法：穷举")
        print(f"  时间复杂度：O(∞)")
        print(f"\n  最优解：{answer}")
        print(f"\n  状态：运行中...")
        print(f"  循环条件：while True")
        print(f"  终止条件：无")
        print(f"\n  无限循环，永不终止")
        print("=" * 40)


if __name__ == "__main__":
    love = Love()
    love.run()
    for msg in love.heartbeat():
        time.sleep(1)
        print(msg)
```

他把光标移到最后，敲下最后一个换行符，然后长长地呼了一口气。

二十多年了。

他写过无数段代码。有的改变了一个行业，有的优化了一个系统，有的修复了一个致命的bug。有的代码让他熬了三个月，有的代码让他在凌晨四点崩溃大哭，有的代码让他差点放弃一切。

但没有哪一段代码，像此刻这一段一样，让他觉得——

每一行都是真的。

他按下回车。

---

姜晚宁看见屏幕上跳出一行行的字。

```
========================================
  陆时屿的人生最优解
========================================

  搜索范围：整个宇宙
  算法：穷举
  时间复杂度：O(∞)

  最优解：姜晚宁

  状态：运行中...
  循环条件：while True
  终止条件：无

  无限循环，永不终止
========================================
```

然后，屏幕上开始一行一行地跳：

```
想你：第1次
想你：第2次
想你：第3次
想你：第4次
......
```

数字在跳动，一秒一次，像心跳。

姜晚宁愣在门口。

她看着屏幕上"最优解"后面的两个字——她的名字，被他用一种程序员特有的方式，嵌进了这段代码里。不是什么华丽的告白，没有玫瑰和烛光，只有最简洁的语法、最朴素的逻辑，和一个while True。

无限循环，永不终止。

她的眼眶一下子就红了。

---

"你什么时候醒的？"

陆时屿听到身后轻微的吸鼻子的声音，转过头，看见姜晚宁站在门口。她披着一件米白色的外套，长发散在肩上，赤着脚踩在地板上，脚趾微微蜷缩着——她紧张或感动的时候，总是会这样。

"刚才。"她走过来，在他身边蹲下，仰头看他，"你在写什么？"

"一段代码。"

"什么代码？"

陆时屿低头看着她，伸手把她鬓边的一缕头发别到耳后，声音很轻："给你的。"

姜晚宁把视线移回屏幕。

那些数字还在跳。想你：第87次，第88次，第89次……每一秒都多一次，像是在认真地、不厌其烦地数着什么。

"我知道你不懂代码。"陆时屿说，"所以我尽量写得简单。"

"我不需要懂代码。"姜晚宁的声音有点哑，"我看得懂'永不终止'。"

陆时屿笑了。

那种笑很淡，嘴角只是微微弯了弯，但眼睛里的光，比屏幕亮。

"我这辈子写了很多代码，"他说，"有的跑了十几年了，还在跑，每天服务几亿用户。有的写完就删了，因为逻辑不对。有的写了一半，发现方向就错了。"

他顿了顿，看着屏幕上不断跳动的数字。

"但这一段，"他说，"这是我写过的最好的代码。"

---

姜晚宁站起来，从背后环住他的脖子，下巴搁在他的肩膀上。

屏幕上的光映在她的睫毛上，一闪一闪的。

"陆时屿。"

"嗯。"

"你知不知道，你这个人，很不浪漫。"

"嗯？"

"全世界大概没有第二个人，会在凌晨一点半，用代码来表白。"

"这已经是我最浪漫的方式了。"

"我知道。"她把脸埋在他的颈窝里，声音闷闷的，"所以我才说——我也是。"

陆时屿侧过头，嘴唇碰了碰她的发顶。

"你也是什么？"

"你是我写过的最好的代码。"

他愣了一下，然后笑了出来——这次是真的笑，笑声从胸腔里震动出来，连带着她靠在他背上的身体也一起微微颤动。

"你又不会写代码。"

"不会写，但我选对了。"姜晚宁说，"选你，是我这辈子的最优解。"

---

屏幕上的数字已经跳到了三百多。

想你：第314次。
想你：第315次。
想你：第316次。

一秒一次，稳定得像一台精密的时钟。

陆时屿伸手握住她环在他脖子上的手，十指交扣。她的手很小，指尖有点凉——他用另一只手覆上去，把她的手整个包住。

"晚宁。"

"嗯？"

"我以前觉得，写代码是一件孤独的事。你坐在电脑前，面对的只有一行行逻辑，没有感情，没有温度。你写的每一行代码，都不会回应你。"

他低头看着两个人交握的手。

"但我后来发现，不是的。代码也可以有心跳。"

"因为写代码的人有心跳？"

"因为写代码的人，心里有人。"

姜晚宁没有说话。她只是把他的手握得更紧了一些。

---

窗外的夜色渐渐淡了，东边的天际线透出一点灰蓝色的光。五月的天亮得早，院子里的蔷薇花在晨雾中轻轻摇晃。

屏幕上的数字还在跳。

想你：第2847次。

如果按这个速度，一天是86400次，一年是31536000次，十年是三亿多次。

但陆时屿在代码里写的是while True。

没有终止条件，没有break，没有exit。

只要程序不被强制关闭——而他不会关闭它——它就会一直跑下去，一秒一秒地跳，一次一次地数，直到时间本身停止。

这就是一个程序员的终极承诺。

不是说"我爱你"，不是说"永远"。

而是写一段代码，让它替你跑完所有的"永远"。

---

天亮了。

姜晚宁在书房的沙发上睡着了，身上盖着陆时屿的外套。她睡着的时候眉头是舒展的，嘴角还带着一点笑意。

陆时屿关掉了书房的顶灯，只留下电脑屏幕的光。他把她的头发从脸上拨开，然后坐在旁边的椅子上，看着屏幕上不断跳动的数字。

想你：第5200次。

刚好是520。

他笑了笑，拿出手机，对着屏幕拍了一张照片。然后他把手机放下，靠在椅背上，闭上了眼睛。

阳光从窗帘的缝隙里照进来，在地板上画出一条细细的金线。

电脑屏幕上，数字还在跳。

一秒一次。

像心跳。

永不停止。
