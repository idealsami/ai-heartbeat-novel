# 第232章 心跳算法（终章）

## 卷六 · 终章

---

夜深了。

城市的霓虹在三十二层的落地窗外渐渐稀疏，像一场盛大的烟花终于走到了尾声。远处的天际线上，最后几盏写字楼的灯也次第熄灭，只剩下路灯橘黄色的光，沿着滨江大道蜿蜒到看不见的地方。

姜晚宁裹着一条薄毯坐在阳台的藤椅上，赤着脚，脚趾蜷在椅垫边缘。五月初的夜风还有些凉，但她不想进屋。今晚的天格外干净，没有云，星星多得不像话——在这座常年被雾霭笼罩的城市里，这样的夜空堪称奢侈。

她微微仰头，辨认着北斗七星的位置。大学时选修过一门天文学通识课，考试勉强及格，唯一记住的就是如何在茫茫星海里找到那七颗星。

身后传来轻微的脚步声。

陆时屿端着两杯热牛奶走过来，一杯递给她，另一杯放在阳台的小桌上。他在她旁边的藤椅上坐下，椅子发出一声轻微的"吱呀"。

"你还不睡？"他问。

"睡不着。"姜晚宁接过牛奶，双手捧着杯子，感受掌心里氤氲的温度，"你呢？"

"代码刚跑完最后一轮测试。"他说这话的时候，语气平淡得像是在说今天吃了什么。

姜晚宁偏头看他。他穿着一件旧的黑色卫衣，袖口微微卷起，露出小臂上一道浅浅的疤痕——那是三年前在实验室调试设备时被零件划伤的，当时缝了四针。她记得很清楚，因为她陪他去的医院，在急诊室外面紧张得来回踱步，被护士误以为是他的家属。

"全部跑完了？"她问。

"嗯。"陆时屿靠在椅背上，目光望向夜空，"全量回归测试，通过率百分之百。"

他说的是"心跳"系统的最终版本。从三年前在车库里写出第一行代码，到现在成为一个覆盖全国三百多家医院的智能医疗辅助系统，这条路走了太久，也太远。中间经历过资金链断裂、核心算法推翻重写、团队解散又重组、无数个通宵达旦的夜晚——以及那些差点让他放弃一切的至暗时刻。

但此刻，这些都过去了。

所有的测试都通过了。

姜晚宁没有接话。她知道他不需要庆祝，不需要香槟和掌声。他需要的，是像现在这样，安安静静地坐在夜空下面，喝一杯热牛奶，和她一起。

沉默在两人之间蔓延开来，但并不令人不安。这种沉默是柔软的，像一条毯子，裹住了他们所有的疲惫和安宁。

过了很久，姜晚宁忽然开口。

"时屿。"

"嗯？"

"我问你一个问题，你别嫌矫情。"

陆时屿微微侧头看她。月光落在她脸上，把她的轮廓勾勒得柔和而清晰。她没有化妆，头发随意扎成一个低马尾，几缕碎发被风吹得贴在脸颊上。

"你问。"他说。

姜晚宁盯着手里的牛奶杯，杯壁上凝着一层细密的水雾。她的拇指无意识地沿着杯沿画圈，一圈又一圈。

"如果重来一次，"她说，声音很轻，像是怕惊扰了头顶的星星，"你还会选我吗？"

这句话从她嘴里说出来的时候，她自己都觉得有些好笑。他们在一起已经四年了，从最初的心动、试探、靠近，到后来的争吵、磨合、妥协，再到如今这种不需要言语就能读懂彼此的默契。这个问题，放在恋爱的第一年问，是少女心事；放在现在问，显得莫名其妙。

可她还是问了。

有些话，不是因为不确定才问的，而是因为想听。

陆时屿没有立刻回答。

这让姜晚宁有些意外。按照她对他的了解，他应该会在零点五秒内给出一个干脆利落的"会"，然后若无其事地继续喝他的牛奶。陆时屿不是那种会花时间斟酌措辞的人——他的大脑处理情感问题的方式和处理代码一样，追求最优解，拒绝冗余。

但他想了很久。

久到姜晚宁开始以为他没听见，正打算再说一遍的时候，他开口了。

"我不会选。"

姜晚宁愣住了。

手里的杯子停在半空中，牛奶的热气袅袅升起，在夜色里很快消散。她转头看向他，眼睛里有一瞬间的茫然，像是一个学生听到了超出考试范围的题。

陆时屿也转头看她。

他的目光很安静，和他平时写代码时那种专注不同，也和他偶尔流露出的温柔不同。这种目光更深，更稳，像是一棵扎了很深的根的树，任凭风吹雨打都不会动摇。

"因为不需要选。"他说。

他的声音不大，但每一个字都清晰得像是被刻进了夜空里。

"从认识你的那天起，我的算法就只有一个最优解。"

姜晚宁的呼吸停了一拍。

不是因为这句话多么华丽或者浪漫——陆时屿从来不是会说漂亮话的人。恰恰相反，他用的是他最熟悉的语言，是逻辑，是算法，是最精确的表达。

"最优解"在计算机科学里的意思是：在所有可行方案中，目标函数取到最大值或最小值的那个唯一答案。不是"还不错"，不是"挺好的"，是所有可能中最好的、不可替代的那一个。

而他说，从认识她的那天起。

不是从表白那天，不是从确认关系那天，是从"认识"那天。

姜晚宁低下头，眼眶有些热。

她想起他们第一次见面的场景。那是大三的冬天，计算机学院和新闻学院联合举办的一场讲座。她迟到了，推开阶梯教室的后门时，所有人都回头看她，只有坐在角落里对着笔记本电脑敲代码的男生连头都没抬。

散场后她在走廊里迷路了——新校区的教学楼她不熟。转了两圈才撞见那个角落里的男生，他正背着双肩包往出口走。她拦住他问路，他才第一次抬头看她。

那个眼神，她记了很多年。

不是惊艳，不是好奇，而是一种……辨认。像是在一堆杂乱的数据里突然找到了那个关键变量，所有的方程瞬间变得简洁而优美。

后来她问他，第一次见面的时候对她什么印象。

他想了半天，说："你推门进来的时候，我正在debug一个递归栈溢出的bug。你打断了我的思路，我本来有点烦。但你问路的时候，我看到你围巾上有个线头，我想帮你拽掉，又觉得不合适。"

"所以呢？"

"所以那个bug我修了一整天。"他说，"明明是个很简单的问题。"

那时候她就知道了，陆时屿这种人，一旦被打扰，就再也回不去了。

"你知道吗，"姜晚宁的声音有点哑，"我有时候会害怕。"

"怕什么？"

"怕你会把我们的关系也当成一个算法。如果哪天算出来我不是最优解了……"

"不会。"他打断她，语气斩钉截铁。

"你都不让我把话说完。"

"因为没有那种'如果'。"陆时屿放下手里的杯子，转过身，正面对着她，"晚宁，你听我说。"

她抬起头，看着他的眼睛。

"我做了十二年的算法研究，我写过上百万行代码，我优化过无数个模型。我可以很确定地告诉你——"他顿了一下，声音忽然变得很温柔，像是在对她一个人说一个只有他们两个才懂的秘密，"在我所有的人生可能性里，你不是一个需要被评估的变量。你是常量。"

常量。

在编程里，常量是永远不会改变的值。一旦被定义，就在整个程序的生命周期里恒定不变。变量可以被重新赋值，可以被覆盖，但常量不行。

它是整个系统的基石。

姜晚宁吸了吸鼻子，笑了一下。"你真的很不会说话。"

"我知道。"

"但我很喜欢。"

"我也知道。"

他伸出手，把她鬓角的碎发别到耳后。动作很轻，指尖的温度微微发凉，触碰到她耳廓的那一刻，她觉得整颗心都被什么东西稳稳地兜住了。

不是心脏骤停的那种心动，是心跳回归正常频率的那种安心。

夜风又吹过来了。姜晚宁靠在他的肩上，把剩下的半杯牛奶喝完。星星在头顶慢慢转动，时间像是被按了慢放键。

不知道过了多久，她感觉到他微微动了一下。

"你冷了？"她问。

"不是。"他说，"想起来一件事。"

"什么事？"

"你等我一下。"

他起身走进屋里。姜晚宁看着他的背影消失在客厅的灯光中，听到他在书房里翻找什么东西。过了一会儿，他端着笔记本电脑走了出来，放在阳台的小桌上。

屏幕亮着，是一个代码编辑器的界面。深色背景，密密麻麻的代码在屏幕上铺展开来，像一片精密的电路。

"你看。"他说。

姜晚宁凑过去看。

那是"心跳"系统核心算法模块的最后一段代码。她跟着他做了三年的项目，虽然不是程序员出身，但基本的代码结构已经能看懂了。

他把光标移到屏幕最下方。

那里有一段注释。

在代码的世界里，注释是一种不会被编译执行的文字。它不产生任何功能，不影响任何运算，它只存在于源代码里，是写代码的人留给自己的、或者留给某些特别的人的一段话。

她看到那两行字——

```
// 最优解：姜晚宁
// 无限循环，永不终止
```

姜晚宁盯着屏幕，一动不动。

屏幕的光映在她的瞳孔里，那两行绿色的注释像两颗星星，安静地亮着。

无限循环。

在编程里，无限循环是一个永远不会停止的程序结构。它可以被手动终止，可以被强制中断，但它本身没有结束的条件。只要程序还在运行，它就会一直循环下去。

永不终止。

她忽然想起很多年前，她在大学新闻采写课上写过一篇人物特稿，标题叫《当程序员遇见爱情》。那时候她还不认识陆时屿，凭想象写了一个浪漫又刻板的故事，被老师打了低分，评语是"缺少真实的细节"。

现在她知道了，真实的细节是什么样的。

真实的细节是一个人在深夜的阳台上，用他最擅长的语言，写下一句永远不会被执行的代码。因为有些话不需要被编译、不需要被运行、不需要输出任何结果——它只需要被写下来。

这就够了。

"你什么时候写的？"她问，声音很轻。

"上个月。最后一次代码评审之前。"他的语气波澜不惊，好像在说一件再平常不过的事，"review的时候，负责代码审计的林工问我这段注释是什么意思。"

"你怎么说的？"

"我说是系统配置说明，他会自动忽略。"

姜晚宁忍不住笑了出来。她笑得肩膀一抖一抖的，眼泪被夜风吹干了，又涌出来新的。

陆时屿看着她笑，嘴角也微微上扬了一点。幅度很小，如果不是她太了解他，几乎看不出来。

"你这个人，"她笑着摇头，"真的很无聊。"

"嗯。"

"但很好。"

"嗯。"

"我也是。"她忽然说。

"什么？"

"我也是最优解。"她抬起下巴，眼睛亮亮的，带着一点少见的得意，"陆时屿，你听好了——在我的算法里，你也是唯一解。没有备选方案，没有降级策略，没有容错冗余。就是你。"

陆时屿沉默了两秒。

然后他笑了。

不是那种微微上扬的、需要仔细辨认的笑，而是真正的、眉眼都弯起来的、像少年一样的笑。

姜晚宁见过他很多种表情——写代码时的专注、debug失败时的烦躁、看到优秀论文时的兴奋、项目上线时的平静、以及每次她生病时藏在冷漠语气下面的心疼。

但她最喜欢的，是他现在这种笑。

不设防的，干净的，像他们最初相遇时的那个冬天的午后。

夜更深了。

星星还在头顶亮着。城市的喧嚣彻底安静下来，只剩下风穿过阳台栏杆时发出的细微声响。远处偶尔传来一两声犬吠，然后又归于沉寂。

姜晚宁靠在他肩上，闭上眼睛。

"困了？"他问。

"嗯。"

"那进去睡吧。"

"再坐一会儿。"她咕哝着，声音已经有些含糊了，"星星还没看完。"

"明天还能看。"

"明天有云。"

"你怎么知道？"

"天气预报说的。"

"你什么时候看的天气预报？"

"刚才你去拿电脑的时候。"

"……"

陆时屿没有再说话。他调整了一下坐姿，让她靠得更舒服一些，然后伸手把滑落的薄毯重新拉到她肩上。

笔记本电脑的屏幕还亮着，光标在最后一行注释后面静静地闪烁，像一颗脉搏。

一下，一下，一下。

不急不缓，稳定而持久。

就像心跳。

姜晚宁的呼吸渐渐变得均匀，她睡着了。

陆时屿低头看了看她的脸。睡着的时候，她的眉头是舒展的，嘴角微微翘着，不知道在做什么梦。

他把电脑合上，没有关机。屏幕暗下去的那一刻，那两行绿色的注释消失在了黑暗里，但他知道它们还在。在源代码的最深处，在整个系统的核心位置，在所有可能被调用、被执行、被运行的代码之上——

它们会一直安静地待在那里。

不会被编译，不会被优化，不会被重构。

就像他自己一样，安安静静地待在她身边，不需要被全世界看到，只需要她知道就够了。

陆时屿靠在椅背上，仰头看着满天繁星。

他想起四年前，他第一次牵她手的那个傍晚。秋天的校园，银杏叶铺了一地金黄，她走在前面，忽然回过头来，把手伸向他。

"走啊。"她说。

那一刻他才明白，人生不需要写那么复杂的算法。有些选择题，答案早就写好了。你要做的，只是伸出手。

夜风轻轻吹过，拂动她额前的碎发。

他低下头，在她发顶落下一个很轻的吻。

晚安。

明天还有很长的路要走，还有很多代码要写，还有很长的未来要一起过。

但此刻，星星很亮，风很轻，她在身边。

这就够了。

这就已经是，最优解。

（全文完）

**作者后记**

这个故事写到最后，我一直在想一个问题：什么是最好的爱情？

后来我想明白了。最好的爱情不是轰轰烈烈的告白，不是惊天动地的牺牲，不是在无数个选择面前做出"正确"的那个决定。

最好的爱情，是根本不需要选择。

因为答案从一开始就在那里。

像一行被写进源代码最深处的注释，不会被执行，不会被看到，但它在那里。

一直都在。

感谢每一个读到最后的你。

愿你也能找到你的最优解。
