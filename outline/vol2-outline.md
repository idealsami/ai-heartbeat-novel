# 卷二·靠近篇 详细章节大纲

## Ch 56-70：各自成长（15章）

### Ch 56 新的战场
- 姜晚宁入职星途汽车，第一天适应新环境
- 认识新同事：林若溪（部门负责人）、周子墨（组长）、陈宇航（同事）
- 第一次产品评审会，展现专业能力
- 晚上跟陆时屿互道晚安

### Ch 57 大厂节奏
- 姜晚宁适应星途的工作节奏，流程规范但复杂
- 开始接手用户体验模块，梳理前任留下的半成品
- 加班到很晚，想起在星辰有人陪她加班

### Ch 58 陆时屿的困境
- 视角切换到陆时屿
- 姜晚宁走后，产品方案推进不顺
- 他开始学着自己写产品说明文档（写得很烂）
- 程朗（项目经理）对他的文档不满意

### Ch 59 第一次深夜通话
- 姜晚宁在星途遇到技术难题，深夜给陆时屿打电话请教
- 他讲了40分钟，耐心解释
- 她说"谢谢你"，他说"不用谢"
- 两人都没挂电话，沉默了10秒，听到彼此的呼吸

### Ch 60 学会解释
- 陆时屿尝试用"人话"写产品文档
- 被程朗退回三次，但他不放弃
- 想起姜晚宁以前教他的技巧

### Ch 61 星途的挑战
- 姜晚宁的产品方案遇到阻力
- 技术团队觉得她要求太高
- 她用在星辰学到的技术理解力说服他们

### Ch 62 天气预报
- 陆时屿开始每天给姜晚宁发天气预报
- 像技术文档一样精准：温度、湿度、风力、空气质量
- 姜晚宁觉得好笑又暖心

### Ch 63 各自的战场
- 姜晚宁在星途站稳脚跟，开始主导产品方案
- 陆时屿在星辰继续深耕泊车系统
- 两人各自忙碌，但每天都会聊几句

### Ch 64 竞品分析
- 姜晚宁研究竞品，发现星辰的泊车系统做得很好
- 她在报告里客观分析，没有偏私
- 周子墨夸她专业

### Ch 65 深夜通话（续）
- 姜晚宁再次遇到技术难题
- 这次是关于传感器融合的问题
- 陆时屿又讲了很长时间
- 挂电话前，两人又沉默了几秒

### Ch 66 陆时屿的进步
- 陆时屿的产品文档终于通过了
- 程朗夸他"有进步"
- 他想告诉姜晚宁，但不知道怎么开口

### Ch 67 周末
- 姜晚宁的周末：在出租屋里看电影
- 陆时屿的周末：在公司加班
- 两人微信聊天，从工作聊到生活

### Ch 68 朋友圈
- 姜晚宁发了一张星途办公楼的照片
- 陆时屿看了很久，但没有点赞
- 宋以晴评论："新环境怎么样？"

### Ch 69 回忆
- 姜晚宁整理东西，发现一张旧照片
- 是星辰科技团队的合影
- 她站在最边上，陆时屿站在最另一边
- 两人都没看镜头

### Ch 70 一个月
- 姜晚宁入职一个月了
- 她已经完全适应了星途的节奏
- 但有时候还是会想起星辰的日子
- 想起那个不会说话的人

## Ch 71-85：行业峰会重逢（15章）

### Ch 71 收到邀请
- 全国智驾行业峰会在上海举办
- 姜晚宁收到邀请，代表星途参加
- 她得知星辰科技也会参加

### Ch 72 上海
- 姜晚宁到达上海，入住酒店
- 峰会规模很大，汇聚了全国智驾行业的精英
- 她在参会名单里看到了陆时屿的名字

### Ch 73 偶遇
- 峰会开幕式上，姜晚宁在人群中看到了陆时屿
- 他穿着正装，差点没认出来
- 她冲他笑，他又愣住了

### Ch 74 重逢
- 两人在会场外聊天
- 三个月没见，都有点拘谨
- 陆时屿问她"在星途还好吗"
- 她说"还好，你呢"

### Ch 75 一起听讲座
- 两人一起去听技术讲座
- 像回到了在星辰搭档的日子
- 陆时屿在某个技术点上跟旁边的人争论
- 姜晚宁在旁边笑着看

### Ch 76 逛展区
- 峰会的展区很大，各种新技术新产品
- 两人一起逛，边走边聊
- 陆时屿在某个展台前驻足很久
- 姜晚宁给他拍照（构图依然很烂）

### Ch 77 晚宴
- 峰会晚宴，两人坐在同一桌
- 有人问他们"你们是同事吗"
- 两人同时说"不是"，又同时说"以前是"

### Ch 78 外滩散步
- 晚宴后，两人溜出会场
- 在上海外滩散步，夜景很美
- 陆时屿鼓起勇气问"你在星途……开心吗？"
- 姜晚宁说"开心，但有时候会想以前。"

### Ch 79 想什么
- 陆时屿追问"想什么？"
- 姜晚宁笑着说"想你做的那个泊车Demo，真的很好。"
- 两个人都知道，这不是全部的答案

### Ch 80 夜上海
- 两人在外滩走了很久
- 聊了很多以前的事
- 陆时屿说"你走之后，我学会写产品文档了"
- 姜晚宁说"那很好啊"

### Ch 81 回酒店
- 两人走回酒店
- 在电梯口告别
- 陆时屿说了句"早点休息"
- 姜晚宁说"你也是"

### Ch 82 失眠
- 姜晚宁在酒店房间里失眠了
- 她看着天花板，想着今晚的对话
- 手机震了一下，陆时屿："今天很开心。"
- 她回："我也是。"

### Ch 83 峰会第二天
- 峰会第二天，两人各自参加不同的分论坛
- 但中午一起吃饭
- 陆时屿给她讲了一个技术冷笑话
- 她笑了很久

### Ch 84 告别
- 峰会结束，两人在机场告别
- 陆时屿说"回去注意安全"
- 姜晚宁说"你也是"
- 两人都没说"下次再见"

### Ch 85 回归
- 姜晚宁回到星途，继续工作
- 陆时屿回到星辰，继续加班
- 但联系频率明显增加了
- 陆时屿开始主动发消息

## Ch 86-100：危机与靠近（15章）

### Ch 86 资金困难
- 星辰科技遭遇资金困难
- 市场环境不好，融资不顺
- 公司开始裁员

### Ch 87 裁员
- 陆时屿虽然技术好，但不是核心管理层
- 他在"优化"名单边缘
- 第一次感到职业危机

### Ch 88 消息
- 姜晚宁从行业群得知星辰裁员的消息
- 她很担心陆时屿
- 但不知道怎么开口问

### Ch 89 试探
- 姜晚宁"碰巧"约陆时屿出来吃饭
- "碰巧"提到星途正在招人
- 陆时屿不傻，看出了她的用心

### Ch 90 自尊心
- 陆时屿内心温暖但犹豫
- 他不想靠关系进去
- 他想靠自己的实力

### Ch 91 面试
- 陆时屿投了简历，通过了星途的筛选
- 技术面全优，面试官很满意
- 他没有告诉姜晚宁

### Ch 92 等待
- 姜晚宁不知道陆时屿面试了
- 她以为他还在犹豫
- 她给他发消息，他回复很慢

### Ch 93 结果
- 陆时屿收到了星途的offer
- 他告诉了姜晚宁
- 姜晚宁说"恭喜你"
- 心里松了一口气

### Ch 94 入职第一天
- 陆时屿入职星途
- 被分到了智驾算法部
- 跟姜晚宁不同部门，但项目有交集

### Ch 95 欢迎回来
- 姜晚宁在他工位上放了一杯美式咖啡
- 附了张纸条："欢迎回来，搭档。"
- 陆时屿看到纸条，愣了很久

### Ch 96 新同事
- 陆时屿认识新同事
- 技术团队很强，压力也更大
- 他需要适应新的技术栈和开发流程

### Ch 97 偶遇
- 两人在公司食堂偶遇
- 像普通同事一样打招呼
- 但眼神里都有点不一样的东西

### Ch 98 项目交集
- 姜晚宁的产品线需要陆时屿的算法支持
- 两人开始有工作上的接触
- 但都保持着专业距离

### Ch 99 宋以晴的观察
- 宋以晴来星途找姜晚宁吃饭
- 她敏锐地察觉到了什么
- "你俩又在同一家公司了？缘分啊"

### Ch 100 默契
- 两人在项目上配合默契
- 像回到了在星辰的日子
- 但这次，感觉不一样了

## Ch 101-110：暧昧升温（10章）

### Ch 101 接触增多
- 两人因为项目频繁接触
- 一起开会、讨论方案、加班
- 距离越来越近

### Ch 102 帮忙
- 陆时屿帮姜晚宁debug一个数据问题
- 两人在会议室对着电脑坐了三小时
- 肩膀偶尔碰到

### Ch 103 心跳
- 姜晚宁心跳加速
- 假装认真看屏幕
- 陆时屿也注意到了，但没说什么

### Ch 104 咖啡
- 陆时屿开始每天给姜晚宁带咖啡
- 美式，不加糖不加奶
- 她喜欢的口味，他记得

### Ch 105 年会
- 公司年会，部门联谊
- 有人追姜晚宁（隔壁部门的销售经理）
- 陆时屿全程黑脸但说不出口

### Ch 106 宋以晴的助攻
- 宋以晴看不下去了
- 把陆时屿拉到角落："你要再不说，她就被别人追走了"
- 陆时屿沉默

### Ch 107 暗流
- 姜晚宁注意到了陆时屿的异样
- 但她不确定那是不是喜欢
- 前男友的阴影让她不敢轻易相信

### Ch 108 团建露营
- 公司团建露营
- 晚上篝火晚会
- 大家都在唱歌聊天

### Ch 109 篝火旁
- 姜晚宁喝了一点酒
- 靠在陆时屿肩上睡着了
- 他一动不动坐了两个小时
- 看着天上的星星

### Ch 110 承认
- 陆时屿终于承认
- 他喜欢她，很喜欢
- 从很久以前就开始了
- 卷二终

## 写作要求

1. **每章3000字左右**
2. **感情线细腻**：注重细节描写，眼神、动作、心理活动
3. **职场专业度**：智驾行业的术语、流程、挑战要真实
4. **双视角切换**：适当切换陆时屿和姜晚宁的视角
5. **节奏把控**：从分离到重逢到暧昧，循序渐进
6. **金句点缀**：每章至少有一个让人印象深刻的句子
7. **伏笔埋设**：为后续卷三的告白做铺垫
